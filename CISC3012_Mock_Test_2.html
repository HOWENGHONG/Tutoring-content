Section A — Marking Guide
Section A——評分要點

  • (a) Acting Humanly = judged by the Turing Test (indistinguishable from a human); Acting Rationally = judged only by correctness of outcome, via math/logic (Rational Agent). “Humanly” is impossible because it requires a precise theory of mind, which we don't have.
    (a) Acting Humanly＝以圖靈測試判斷（與人類無法區分）；Acting Rationally＝只看結果是否正確，透過數學／邏輯（Rational Agent）。「像人」不可能是因為需要精確的心智理論，但我們沒有
  • (b) States = arrangement of 8 tiles + blank in a 3x3 grid; Initial state = given starting arrangement; Successor function = blank moves up/down/left/right; Goal test = matches goal configuration; Path cost = each step costs 1.
    (b) 狀態＝3x3格中8個方塊+空格的排列；初始狀態＝給定的起始排列；後繼函數＝空格上下左右移動；目標測試＝符合目標排列；路徑成本＝每步成本為1
  • (c) BFS: complete (yes), optimal (yes, if cost non-decreasing), high time/space complexity. DFS: complete (no), optimal (no), lower time/space complexity. IDS: complete (yes), optimal (yes, if step cost=1), reasonable time/space complexity.
    (c) BFS：完備（是）、最優（是，若成本隨深度非遞減）、時間/空間複雜度高。DFS：完備（否）、最優（否）、時間/空間複雜度較低。IDS：完備（是）、最優（是，若步驟成本=1）、時間/空間複雜度合理
  • (d) (1) Don't return to parent state; (2) don't create cycles (check ancestors); (3) don't generate any previously-generated state — uses a closed list (a set of all expanded nodes); if a node matches one already in it, it's discarded.
    (d) (1)不回到父節點；(2)不產生含環的路徑（檢查祖先）；(3)不產生任何先前已生成過的狀態——用closed list（已展開節點的集合）；若節點已在其中則捨棄
