Section F — Sentence Rearrangement(20% @5)

Rearrange the following words or phrases to form a complete sentence. Change the forms of the words and add extra words where necessary. 排列句子，可改變詞形及加字。

1. Be passionate about something/doing something
( my uncle / cooking / be / very / traditional dishes )
參考答案: My uncle is very passionate about cooking traditional dishes.
2. Penalise somebody for something/doing something
( the referee / the player / arguing )
參考答案: The referee penalised the player for arguing.
3. Be intended for somebody/something
( this workshop / beginners / who / want / to learn baking )
參考答案: This workshop is intended for beginners who want to learn baking.
4. Keep somebody/something in mind
( you / this rule / should / always )
參考答案: You should always keep this rule in mind.
