Section A——參考答案

EN: (a) Frontier values are f = g + h.
S: f = 0 + 7 = 7. Expand S → A (1 + 6 = 7), B (4 + 4 = 8).
Expand A (7) → B via A: g = 3, f = 3 + 4 = 7 (better than 8), C: g = 6, f = 8, G: g = 13, f = 13.
Expand B (7) → C via B: g = 5, f = 7 (better than 8).
Expand C (7) → G: g = 8, f = 8 (better than 13).
Expand G (8): goal. Path S–A–B–C–G, cost 1 + 2 + 2 + 3 = 8 (optimal). h is admissible: true costs to G are S 8, A 7, B 5, C 3 and every h is at most that.
中文：(a) Frontier 的值是 f = g + h。
S:f = 0 + 7 = 7。展開 S → A(1 + 6 = 7)、B(4 + 4 = 8)。
展開 A(7)→ 經 A 到 B:g = 3、f = 3 + 4 = 7(比 8 好);C:g = 6、f = 8;G:g = 13、f = 13。
展開 B(7)→ 經 B 到 C:g = 5、f = 7(比 8 好)。
展開 C(7)→ G:g = 8、f = 8(比 13 好)。
展開 G(8):是 goal。路徑 S–A–B–C–G,成本 1 + 2 + 2 + 3 = 8(optimal)。h 是 admissible:到 G 的真實成本為 S 8、A 7、B 5、C 3,每個 h 都不超過。

EN: (b) Greedy uses f = h only. S → A (6), B (4); pick B (4). Expand B → C (2), A (6); pick C (2). Expand C → G (0); pick G. Path S–B–C–G, cost 4 + 2 + 3 = 9, but the optimal cost is 8. Greedy ignores g(n): the cheap first edge S–A (1) looks bad only because h(A) = 6 is larger than h(B) = 4, so it never considers the cheaper route through A.
中文：(b) Greedy 只用 f = h。S → A(6)、B(4);選 B(4)。展開 B → C(2)、A(6);選 C(2)。展開 C → G(0);選 G。路徑 S–B–C–G,成本 4 + 2 + 3 = 9,但最佳成本是 8。Greedy 忽略 g(n):便宜的第一步 S–A(1)只因為 h(A) = 6 比 h(B) = 4 大就被忽略,所以沒考慮經過 A 的較便宜路線。

EN: (c) Start: 2 8 3 / 1 6 4 / 7 _ 5; goal: 1 2 3 / 8 _ 4 / 7 6 5.
h1: tiles 2, 8, 1, 6 are misplaced (3, 4, 7, 5 are in place) → h1 = 4.
h2: tile 2 is 1 square from its goal, 8 is 2 (one down, one left), 1 is 1, 6 is 1 → 1 + 2 + 1 + 1 = 5.
h2 ≥ h1 for every state, so h2 dominates h1 (smaller effective branching factor). Both are admissible: h1 comes from the relaxed rule 'a tile can jump to any square', h2 from 'a tile can move to any adjacent square', so each is at most the true cost.
中文：(c) 起始:2 8 3 / 1 6 4 / 7 _ 5;目標:1 2 3 / 8 _ 4 / 7 6 5。
h1:2、8、1、6 位置錯誤(3、4、7、5 正確)→ h1 = 4。
h2:tile 2 離目標 1 格、8 離目標 2 格(一下一左)、1 離 1 格、6 離 1 格 → 1 + 2 + 1 + 1 = 5。
所有狀態都有 h2 ≥ h1,所以 h2 dominates h1(effective branching factor 較小)。兩者都 admissible:h1 對應放寬規則「tile 可跳到任何格」,h2 對應「tile 可移到任何相鄰格」,所以都不超過真實成本。

EN: (d) Start: all domains {R, G, B}.
A = R → FC removes R from B: B {G, B}. Others unchanged.
B = G → FC: A done; C loses G → {R, B}; D loses G → {R, B}. E still {R, G, B}.
MRV: C and D both have 2 values; E has 3. Pick C (tie broken alphabetically). C = R → D loses R → D {B}.
MRV picks D (1 value): D = B → E loses B → E {R, G}. Assign E = R (or G).
Solution: A = R, B = G, C = R, D = B, E = R. Check: A≠B, B≠C, C≠D, B≠D, D≠E all hold.
中文：(d) 起始:所有 domain 都是 {R, G, B}。
A = R → FC 把 R 從 B 刪掉:B {G, B}。其他不變。
B = G → FC:A 已指派;C 刪掉 G → {R, B};D 刪掉 G → {R, B}。E 仍是 {R, G, B}。

Explanations
解釋

  • 1-C (Ch1) The basic test needs NLP, knowledge representation, automated reasoning and machine learning. The Total test adds computer vision and robotics. — 基本測試需要 NLP、知識表示、自動推理、機器學習。Total 版本再加電腦視覺(看)和機器人(動)。
  • 2-B (Ch1) We understand our own brains only a little, and humans act irrationally, so human-like systems are unreliable. A rational agent is judged only by the correctness of its outcome. — 我們對自己大腦所知有限,人類也會不理性,所以人類式系統不可靠。Rational agent 只看結果是否正確。
  • 3-B (Ch1) Rational means: given the facts (inputs), act in order to achieve the given goals. It does not mean imitating humans or being perfect. — Rational:給定 facts(inputs),為了達成給定的 goals(objectives)而行動。不是模仿人,也不保證零錯誤。
  • 4-B (Ch1) A traditional algorithm cannot be written if humans cannot solve the problem. An AI program can be learned from data directly (rules, trees or neural networks). — 人不會解的問題寫不出傳統演算法。AI 可直接從資料學出規則、決策樹或神經網絡。
  • 5-A (Ch1) Risks include reliability, security, misuse such as fake news, and challenges to jobs. The lecture says humans are replaced largely but not completely. — 風險包括可靠性、安全、假新聞等濫用,以及對工作的挑戰。講義說的是「大致取代、不是完全取代」。
  • 6-A (Ch2) The four items: performance measure P, prior knowledge of the environment, the actions the agent can perform, and the percept sequence so far. — 四項:績效指標 P、對環境的先驗知識、可執行的動作、到目前為止的感知序列。
  • 7-A (Ch2) A simple reflex agent uses only condition-action rules with no memory, so it needs full observability (e.g. a chess board). — 簡單反射 agent 只用 condition-action 規則、沒有記憶,所以需要完全可觀察(如棋盤)。
  • 8-B (Ch2) It keeps an internal state summarising the percept history, to handle partially observable worlds. — 它保留總結感知歷史的內部狀態,用來處理部分可觀察的世界。
  • 9-B (Ch2) Taxi driving is stochastic (unobservable factors, noise), sequential and multi-agent. — Taxi 是 stochastic(有未觀察因素與雜訊)、sequential、多 agent。
  • 10-B (Ch2) A goal is only achieved or not. Utility maps a state to a real number, which handles conflicting goals and trade-offs. — 目標只有達成/未達成。Utility 把狀態映射成實數,可處理目標衝突與取捨。
