Ch1–3 Must remember · 第一至三章必記

  • Turing Test needs NLP, knowledge representation, automated reasoning, machine learning; Total adds vision and robotics. — Turing Test 需要 NLP、知識表示、自動推理、機器學習;Total 再加視覺與機器人。
  • Rationality depends on: performance measure, prior knowledge, actions, percept sequence. — Rationality 取決於:績效指標、先驗知識、動作、感知序列。
  • Five agents: simple reflex → model-based reflex → goal-based → utility-based → learning. — 五種 agent:簡單反射 → 模型反射 → 目標導向 → 效用導向 → 學習。
  • Environment pairs: observable, deterministic, episodic, static, discrete, single/multi-agent. — 環境六對性質:可觀察性、確定性、獨立性、靜態性、離散性、單/多 agent。
  • Problem = initial state + successor function + goal test + path cost. — 問題 = 初始狀態 + 後繼函數 + 目標測試 + 路徑成本。
  • BFS O(b^(d+1)) both; UCS O(b^⌈C*/ε⌉); DFS O(b^m) time and O(bm) space; DLS O(b^l), O(bl); IDS O(b^d), O(bd); bidirectional O(b^(d/2)). — BFS 時間與空間 O(b^(d+1));UCS O(b^⌈C*/ε⌉);DFS 時間 O(b^m)、空間 O(bm);DLS O(b^l)、O(bl);IDS O(b^d)、O(bd);雙向 O(b^(d/2))。
  • Only DFS and DLS are NOT complete; only DFS and DLS are NOT optimal (BFS/IDS optimal when step costs are equal). — 只有 DFS 與 DLS 不 complete;只有 DFS 與 DLS 不 optimal(BFS/IDS 在 step cost 相同時 optimal)。

Ch4 Must remember · 第四章必記

  • Greedy f = h (not optimal, incomplete). A* f = g + h (complete and optimal if h is admissible). — Greedy f = h(不 optimal、不 complete)。A* f = g + h(h admissible 時 complete 且 optimal)。
  • Romania: greedy 450, A* 418. A* stops when the goal is selected for expansion. — Romania:greedy 450、A* 418。A* 在 goal 被選出展開時才停。
  • 8-puzzle: h1 = misplaced tiles (8), h2 = Manhattan (18), true 26; h2 dominates h1. — 8-puzzle:h1 = 錯位格數(8)、h2 = 曼哈頓(18)、真實 26;h2 dominates h1。
  • b* smaller is better; N = 1 + b* + … + (b*)^d. If unsure, h = max(h1, …, hm). — b* 越小越好;N = 1 + b* + … + (b*)^d。不確定時用 h = max(h1, …, hm)。
  • Hill-climbing fails at local maxima, ridges, plateaux; fix with random restart. Beam search: best k of m·k. GA: selection, crossover, mutation. — Hill-climbing 會卡在 local maxima、ridges、plateaux;用 random restart 補救。Beam search:m·k 中選最好 k 個。GA:selection、crossover、mutation。

Ch5 Must remember · 第五章必記

  • CSP = <X, C>; solution = complete + consistent; O(d^n) assignments (Australia 3^7). — CSP = <X, C>;解 = complete + consistent;O(d^n) 種指派(Australia 為 3^7)。
  • Order: MRV first; degree heuristic to break the first tie (SA = 5); LCV for the value. — 順序:先 MRV;第一步用 degree 破平手(SA = 5);選值用 LCV。
  • FC prunes neighbours; AC also checks arcs between unassigned variables (NT–SA); AC is stronger. — FC 修剪鄰居;AC 還檢查未指派變數間的弧(NT–SA);AC 較強。
  • WA = red, Q = green: NT, SA = {blue} (FC misses the NT–SA conflict, AC finds it). WA = red, Q = green, V = blue: Dom(SA) = { }. — WA = red、Q = green:NT、SA = {blue}(FC 看不出 NT–SA 衝突,AC 看得出)。WA = red、Q = green、V = blue:Dom(SA) = { }。
  • Independent subproblems: O(d^n) → O(d^c · n/c); tree-structured CSP: linear time; min-conflicts: runtime independent of size. — 獨立子問題:O(d^n) → O(d^c · n/c);樹狀 CSP:線性時間;min-conflicts:時間與規模無關。

Ch6 Must remember · 第六章必記

  • TELL adds, ASK queries; truth table 2^n rows; Wumpus KB has 7 symbols, 128 rows. — TELL 加入、ASK 查詢;truth table 有 2^n 列;Wumpus KB 有 7 個符號、128 列。
  • ¬B11 and B11 ⇔ (P12 ∨ P21) imply no pit at [1,2] or [2,1]. — ¬B11 且 B11 ⇔ (P12 ∨ P21) 推得 [1,2]、[2,1] 都沒有坑。
  • P ⇒ Q is false only when P is true and Q is false. — P ⇒ Q 只有 P 真 Q 假時為 false。
  • ∀ with ⇒, ∃ with ∧. ∀x∃y ≠ ∃y∀x. ¬∀x P ≡ ∃x ¬P; ¬∃x P ≡ ∀x ¬P. — ∀ 配 ⇒,∃ 配 ∧。∀x∃y ≠ ∃y∀x。¬∀x P ≡ ∃x ¬P;¬∃x P ≡ ∀x ¬P。
  • PL lacks expressiveness; FOL adds objects, relations, functions, quantifiers, but not categories, time, events. — PL 缺乏表達力;FOL 加入 objects、relations、functions、量詞,但沒有 categories、time、events。
