Chapter 1 — What is AI? · 第一章 — 什麼是 AI?

Definitions and approaches · 定義與做法

  • There is no universal definition of AI. The four views are: think humanly, act humanly, think rationally, act rationally. — AI 沒有統一定義。四種觀點:像人一樣思考、像人一樣行動、理性地思考、理性地行動。
  • Humanly systems are unreliable: we do not know how our brains work, and humans act irrationally. Rational systems only care about the correctness of the outcome and mostly use mathematical and logical models. — 人類式系統不可靠:我們不懂大腦如何運作,人類也會不理性。Rational 系統只在乎結果是否正確,多用數學和邏輯模型。
  • Turing Test: a human questioner communicates remotely and cannot tell whether a computer or a human is answering. It needs natural language processing, knowledge representation, automated reasoning and machine learning. The Total Turing Test adds computer vision and robotics. — Turing Test:提問者以遠端文字溝通,分不出對方是電腦還是人。需要自然語言處理、知識表示、自動推理、機器學習。Total Turing Test 再加電腦視覺與機器人。
  • A rational agent perceives the environment and, given facts, acts to achieve its given goals. The reasoning in between is designed by humans, usually with maths and logic. — Rational agent 感知環境,給定事實後為達成既定目標而行動。中間的推理由人類設計,通常用數學與邏輯。

Capability, limits and risks · 能力、限制與風險

  • AI has no limit in application, but limited capability: it can replace many labour-intensive jobs, while humans still do better in intelligence-intensive jobs. — AI 的應用沒有限制,但能力有限:可以取代許多勞力密集的工作,智力密集的工作人類仍然做得較好。
  • State of the art: monitoring spacecraft, Go, driving, logistics planning (weeks to hours, up to 50,000 vehicles), surgical robotics, image classification, language and generative AI. — 尖端應用:太空船監控、圍棋、駕駛、物流規劃(數週縮至數小時,最多 50,000 個車輛)、手術機器人、圖像分類、語言與生成式 AI。
  • Risks: reliability, security, misuse such as fake news, and the impact on jobs and recruitment. — 風險:可靠性、安全、假新聞等濫用,以及對工作與招聘的衝擊。
  • AI vs traditional programs: traditional logic is designed by humans, so if humans cannot solve it, the algorithm cannot be written. AI learns rules or neural networks from data directly. With LLM agents, natural language becomes machine code, but we still learn programming, less intensively. — AI 與傳統程式:傳統邏輯由人設計,人不會解就寫不出。AI 直接從資料學出規則或神經網絡。有了 LLM agent,自然語言可轉成機器碼,但我們仍需學編程,只是不必那麼深入。

Chapter 2 — Intelligent Agents · 第二章 — 智能代理

Agents and rationality · Agent 與理性

  • An agent perceives the environment through sensors and acts on it through actuators. A lookup table cannot implement the agent function (infinite length), so an agent program is used. — Agent 透過感測器感知環境,並透過執行器作用於環境。查表無法實現 agent function(長度無限),所以用 agent program。
  • Rationality depends on four things: the performance measure P, the agent's prior knowledge of the environment, the actions it can perform, and the percept sequence so far. — Rationality 取決於四件事:績效指標 P、agent 對環境的先驗知識、可執行的動作、到目前為止的感知序列。
  • Vacuum world example: 1 point per clean square per time step over 10,000 steps with 2 squares gives a maximum of 20,000. — 吸塵器世界例子:2 格、共 10,000 步、每步每個乾淨格 1 分,最高 20,000。

PEAS and environment properties · PEAS 與環境性質

  • PEAS = Performance measure, Environment, Actuators, Sensors. Taxi: actuators are accelerator, steering, braking, display; sensors include cameras, GPS and customer interaction. — PEAS = 績效指標、環境、執行器、感測器。Taxi:執行器為油門、轉向、剎車、顯示器;感測器包括攝影機、GPS 與乘客互動。
Property pair — 性質配對Meaning — 意思
Fully / partially observable — 完全 / 部分可觀察Sensors can / cannot see the complete state — 感測器能 / 不能看到完整狀態
Deterministic / stochastic — 確定性 / 隨機性Next state fully determined by state + action, or not (taxi: stochastic) — 下一狀態是否完全由當前狀態與動作決定(taxi:隨機)

Single / multi-agent — 單 / 多 agentCrossword = single; chess = competitive; taxi = cooperative — 填字 = 單;西洋棋 = 競爭;taxi = 合作

Five agent types · 五種 agent

  • Simple reflex: condition-action rules, needs full observability. Model-based reflex: adds an internal state for partially observable worlds. Goal-based: chooses actions toward a goal. Utility-based: utility maps a state to a real number, so it handles conflicting goals and trade-offs. Learning agent: improves from environment feedback using machine learning. — Simple reflex:condition-action 規則,需要完全可觀察。Model-based reflex:多了內部狀態,用於部分可觀察世界。Goal-based:朝目標選擇動作。Utility-based:utility 把狀態映射成實數,能處理目標衝突與取捨。Learning agent:用機器學習根據環境回饋進步。

Chapter 3 — Rational Agent by Searching · 第三章 — 以搜尋實現 Rational Agent

Problem formulation · 問題形式化

  • Goal-based agents are implemented as a search over states. The environment must be static, fully observable, discrete and deterministic. — 目標導向 agent 以狀態搜尋實現。環境必須是靜態、完全可觀察、離散且確定性的。
  • A well-defined problem has four components: initial state, successor function, goal test and path cost function g. A solution is a path from the initial state to a state satisfying the goal test; the optimal solution has the lowest path cost. — Well-defined problem 有四個要素:initial state、successor function、goal test、path cost function g。Solution 是從初始狀態到滿足 goal test 的路徑;optimal solution 是成本最低者。
  • A node has five parts: STATE, PARENT-NODE, ACTION, PATH-COST g(n), DEPTH. The fringe is the set of unexpanded leaf nodes, kept in a queue. — Node 有五個部分:STATE、PARENT-NODE、ACTION、PATH-COST g(n)、DEPTH。Fringe 是尚未展開的 leaf nodes,存放在 queue。
  • 8-queens: incremental formulation starts from an empty board and adds queens; complete-state formulation starts with all 8 queens and moves attacked ones (at most 7! = 5040, about 2^12 states, instead of about 2^48 states). The formulation changes the search-space size a lot. — 8-queens:incremental 從空盤加皇后;complete-state 從 8 個皇后開始再移動被攻擊的(狀態數由約 2^48 縮到約 2^12)。形式化方式大大改變搜尋空間大小。

Chapter 4 — Informed Search and Local Search · 第四章 — Informed Search 與 Local Search

Informed search · Informed search

  • Best-first search orders the fringe by an evaluation function f(n). Greedy: f = h; incomplete, not optimal, poor. A*: f = g + h; complete and optimal when h is admissible (never overestimates). h_SLD is admissible. — Best-first 以評估函數 f(n) 排序 fringe。Greedy:f = h;incomplete、not optimal、表現差。A*:f = g + h;h 為 admissible(永不高估)時 complete 且 optimal。h_SLD 是 admissible。
Romania, Arad to Bucharest
Greedy : Arad-Sibiu-Fagaras-Bucharest = 140+99+211 = 450 (not optimal)
A*     : Arad-Sibiu-RV-Pitesti-Bucharest = 140+80+97+101 = 418 (optimal)
  • IDA* = iterative deepening + A*, cutoff on f-cost; the next cutoff is the smallest f that exceeded the previous one. It saves memory. — IDA* = iterative deepening + A*,以 f-cost 為 cutoff;下一個 cutoff 是上一輪超出者中最小的 f。可節省記憶體。
  • Heuristic quality: effective branching factor b* from N = 1 + b* + (b*)² + … + (b*)^d; smaller b* is better. h2 dominates h1 if h2(n) ≥ h1(n) for all n, and both are admissible. Use the largest admissible h. — 啟發函數品質:effective branching factor b* 由 N = 1 + b* + (b*)² + … + (b*)^d 定義;b* 越小越好。若 h2(n) ≥ h1(n) 對所有 n 成立且兩者都 admissible,則 h2 dominates h1。用最大的 admissible h。
  • 8-puzzle example: h1 = number of misplaced tiles = 8, h2 = sum of Manhattan distances = 3 + 1 + 2 + 2 + 2 + 3 + 3 + 2 = 18, true cost 26. — 8-puzzle 例:h1 = 錯位格數 = 8,h2 = 曼哈頓距離總和 = 3 + 1 + 2 + 2 + 2 + 3 + 3 + 2 = 18,真實成本 26。
  • Inventing heuristics: the exact cost of a relaxed problem is admissible for the original; if unsure, use h = max(h1, …, hm); the cost of a subproblem solution is also a lower bound. — 設計啟發函數:放寬問題的精確解成本對原問題是 admissible;不確定時用 h = max(h1, …, hm);子問題的解成本也是下界。

Local search · Local search

  • Local search keeps only a current state and moves to neighbours. It uses constant memory and suits large or continuous spaces and optimisation. It is incomplete and not optimal in theory. — Local search 只保留目前狀態並移到鄰居。記憶體固定,適合大型或連續空間與最佳化。理論上 incomplete 且 not optimal。
  • Hill-climbing moves to the best neighbour. Failures: local maxima, ridges, plateaux. Random-restart hill-climbing repeats from random starts and keeps the best. — Hill-climbing 移到最佳鄰居。失敗情形:local maxima、ridges、plateaux。Random-restart hill-climbing 從隨機起點重複並保留最佳結果。
  • Local beam search keeps k states and picks the best k of all m·k successors (the searches cooperate). Stochastic beam search picks k at random. — Local beam search 保留 k 個 state,從所有 m·k 個後繼中挑最好的 k 個(搜尋之間會合作)。Stochastic beam search 隨機挑 k 個。
  • Genetic algorithm: population of k strings; fitness (8-queens: non-attacking pairs, max 28); select parents by fitness (24, 23, 20, 11 gives 31%, 29%, 26%, 14%); crossover at a random point (32752/411 + 24748/552 gives 32748552); mutation with small probability; keep the best k of the 2k. — Genetic algorithm:k 個字串的 population;fitness(8-queens:互不攻擊的皇后對,最大 28);依 fitness 選 parent(24、23、20、11 對應 31%、29%、26%、14%);在隨機切點 crossover(32752/411 + 24748/552 得 32748552);以小機率 mutation;從 2k 個中保留最好的 k 個。

Chapter 5 — Constraint Satisfaction Problems · 第五章 — 約束滿足問題 CSP

Definitions · 定義

  • A CSP is <X, C>: variables with domains and constraints. It gives a standard representation so general-purpose algorithms work. A solution is a complete and consistent assignment. Possible complete assignments: O(d^n), e.g. 3^7 for Australia. — CSP 是 <X, C>:有 domain 的變數與 constraints。它提供標準表示,讓通用演算法可用。Solution 是 complete 且 consistent 的指派。可能的 complete assignment:O(d^n),如 Australia 為 3^7。
  • Unary constraints are preprocessed by removing values from the domain. Binary constraints form a constraint graph. Higher-order constraints (Alldiff, cryptarithmetic) need a hypergraph or are split into binary ones. — Unary constraint 以刪除 domain 的值預處理。Binary constraint 形成 constraint graph。Higher-order constraint(Alldiff、cryptarithmetic)需要 hypergraph,或拆成 binary。

Solving with backtracking · 以 backtracking 求解

  • Incremental formulation: start from the empty assignment, choose an unassigned variable, assign a non-conflicting value. Solutions appear at depth n, so DFS (backtracking) is complete. — Incremental formulation:從空指派開始,選一個未指派變數,指派不衝突的值。解出現在深度 n,所以 DFS(backtracking)是 complete。
Heuristic — 方法Idea — 概念
MRVChoose the variable with the fewest legal values (fail-first) — 選合法值最少的變數(fail-first)
Degree heuristic — DegreeChoose the variable with the most constraints on unassigned variables; used for the first pick (SA has degree 5) — 選牽涉最多未指派變數 constraint 的變數;用於第一步(SA degree = 5)
Least-constraining value — LCVChoose the value that leaves neighbours the most choices — 選讓鄰居保留最多選擇的值
Forward checking — FCAfter assigning X, delete inconsistent values from neighbours' domains; empty domain means backtrack — 指派 X 後,刪除鄰居 domain 中不一致的值;出現空 domain 就回溯
Arc consistency — ACFor every x in Dom(X) there is a compatible y in Dom(Y); also catches conflicts between unassigned variables (NT–SA); repeat until stable — Dom(X) 中每個 x 在 Dom(Y) 都有相容的 y;也能發現未指派變數間的衝突(NT–SA);重複到穩定
Min-conflicts — Min-conflictsLocal search on a complete assignment; pick the value with the fewest conflicts; runtime almost independent of size — 在 complete assignment 上做 local search;選衝突最少的值;執行時間幾乎與問題大小無關
  • Example: WA = red, Q = green. FC leaves NT and SA with {blue}, but they are adjacent: arc consistency detects it at once, FC only after a further assignment. With WA = red, Q = green, V = blue, Dom(SA) is empty, so FC backtracks. — 例:WA = red、Q = green。FC 讓 NT 與 SA 都只剩 {blue},但兩者相鄰:AC 立刻發現,FC 要再指派後才發現。WA = red、Q = green、V = blue 時 Dom(SA) 為空,FC 回溯。

Problem structure · 問題結構

  • Independent subproblems (T in Australia) are solved separately: O(d^n) becomes O(d^c · n/c), linear in n. A tree-structured CSP is solved in linear time. To reduce a graph to a tree: remove nodes (fix SA) or combine nodes (tree decomposition with mega-variables). Decomposition rules: every variable and every constraint appears in some subproblem; a variable in two subproblems appears on the whole path between them. — 獨立子問題(Australia 的 T)分開解:O(d^n) 變成 O(d^c · n/c),對 n 線性。Tree-structured CSP 可在線性時間解。把圖化成樹:移除節點(固定 SA)或合併節點(用 mega-variable 的 tree decomposition)。分解規則:每個變數與每個 constraint 都出現在某個子問題;變數出現在兩個子問題時,必須出現在兩者之間路徑上的所有子問題。

Chapter 6 — Logical Agents · 第六章 — 邏輯代理

Knowledge-based agents and Wumpus world · 知識型 agent 與 Wumpus world

  • A KB is a set of sentences. TELL adds sentences, ASK queries them, and the inference engine answers. This helps in partially observable environments. — KB 是一組 sentence。TELL 加入 sentence,ASK 查詢,inference engine 回答。對部分可觀察環境很有幫助。
  • Wumpus PEAS: +1000 for gold, −1000 for death, −1 per action, −10 for the arrow; 4×4 grid starting at [1,1]; actions Forward, Turn, Grab, Shoot (one arrow); percepts [Stench, Breeze, Glitter, Bump, Scream]. About 21% of worlds have no safe solution. — Wumpus PEAS:拿到金子 +1000、死亡 −1000、每個動作 −1、用掉箭 −10;4×4 格,從 [1,1] 出發;動作 Forward、Turn、Grab、Shoot(一支箭);感知 [Stench, Breeze, Glitter, Bump, Scream]。約 21% 的世界沒有安全解。

Propositional logic · 命題邏輯

  • Symbols and connectives ¬ ∧ ∨ ⇒ ⇔. In P ⇒ Q, P is the antecedent and Q the consequent. A truth table with n symbols has 2^n rows, which is too big, so use inference rules (Modus Ponens, And-Elimination) and equivalences (De Morgan, contraposition, implication elimination). — 符號與連接詞 ¬ ∧ ∨ ⇒ ⇔。P ⇒ Q 中 P 是 antecedent、Q 是 consequent。n 個符號的 truth table 有 2^n 列,太大,所以用 inference rules(Modus Ponens、And-Elimination)與等價式(De Morgan、contraposition、implication elimination)。
KB: R1 ¬P11; R2 B11 <=> (P12 v P21); R3 B21 <=> (P11 v P22 v P31); R4 ¬B11; R5 B21
7 symbols -> 2^7 = 128 rows. From R4 and R2: P12 = false and P21 = false,
so KB entails ¬P12: square [1,2] has no pit.
  • Weakness: lack of expressiveness. Every square and orientation needs its own propositions (1000+ rules even for 4×4). — 弱點:缺乏表達力。每個格子與朝向都要各自的命題(4×4 就要上千條規則)。

First-order logic · 一階邏輯

  • FOL adds objects, relations (predicates), functions and quantifiers, so one rule covers a whole class of objects. A model also contains a domain of objects (the example has 5 objects, 2 binary relations, 3 unary relations and 1 function). FOL lacks mechanisms for categories, time and events. — FOL 加入 objects、relations(predicates)、functions 與量詞,一條規則就能涵蓋一整類物件。Model 還包含 objects 的 domain(例子有 5 個 objects、2 個 binary relations、3 個 unary relations、1 個 function)。FOL 沒有 categories、time、events 的機制。
  • ∀ pairs with ⇒: ∀x King(x) ⇒ Person(x). ∃ pairs with ∧: ∃x Crown(x) ∧ OnHead(x, John). Quantifiers do not commute: ∀x∃y Loves(x,y) means everybody loves somebody; ∃y∀x Loves(x,y) means somebody is loved by everybody. — ∀ 配 ⇒:∀x King(x) ⇒ Person(x)。∃ 配 ∧:∃x Crown(x) ∧ OnHead(x, John)。量詞不可交換:∀x∃y Loves(x,y) 是每個人都愛某個人;∃y∀x Loves(x,y) 是有某人被所有人愛。
  • De Morgan for quantifiers: ¬∀x P ≡ ∃x ¬P; ¬∃x P ≡ ∀x ¬P; ∀x P ≡ ¬∃x ¬P; ∃x P ≡ ¬∀x ¬P. Prolog uses only ∀. — 量詞的 De Morgan:¬∀x P ≡ ∃x ¬P;¬∃x P ≡ ∀x ¬P;∀x P ≡ ¬∃x ¬P;∃x P ≡ ¬∀x ¬P。Prolog 只用 ∀。
