Ch3 Search

Term中文Meaning 意思
Initial state初始狀態Where the agent starts — agent 的起點
Successor function後繼函數All possible actions and resulting states — 所有可能的動作與結果狀態
Goal test目標測試Checks whether a state is a goal — 檢查是否為目標狀態
Path cost路徑成本Sum of step costs, g(n) — 各步成本總和 g(n)
State space狀態空間All states reachable from the initial state — 從初始狀態可到達的所有狀態
Fringe / frontier邊界Unexpanded leaf nodes — 尚未展開的 leaf nodes
Expand展開Apply the successor function to a node — 對節點套用後繼函數
Branching factor (b)分支因子Number of successors per node — 每個節點的後繼數
Completeness完備性Guaranteed to find a solution if one exists — 有解就保證找得到
Optimality最佳性Finds the lowest-cost solution — 找到成本最低的解
Breadth-first search (BFS)廣度優先搜尋Expands shallowest node first, FIFO — 先展開最淺的節點,FIFO
Uniform-cost search一致成本搜尋Expands the lowest g(n) — 先展開 g(n) 最小者
Depth-first search (DFS)深度優先搜尋Expands deepest node first, LIFO — 先展開最深的節點,LIFO
Depth-limited search限深搜尋DFS with a depth limit — 有深度上限的 DFS
Iterative deepening search迭代加深搜尋Repeats DFS with limits 0, 1, 2, … — 以上限 0, 1, 2… 重複做 DFS
Bidirectional search雙向搜尋Forward from start and backward from goal — 從起點正向、從目標反向
Closed list已展開表Set of expanded states used to discard repeats — 存放已展開 state 以丟棄重複

Ch4 Informed & Local Search

Term中文Meaning 意思
Informed (heuristic) search有資訊(啟發式)搜尋Uses problem-specific information — 使用與問題相關的資訊
Evaluation function f(n)評估函數Ranks nodes for expansion — 為節點的展開順序排序
Heuristic function h(n)啟發函數Estimated cost from n to the goal — n 到目標的估計成本
Greedy best-first search貪心最佳優先搜尋f(n) = h(n) — f(n) = h(n)
A* searchA* 搜尋f(n) = g(n) + h(n) — f(n) = g(n) + h(n)
Admissible heuristic可採納啟發函數Never overestimates the cost to the goal — 永不高估到目標的成本
Straight-line distance (h_SLD)直線距離An admissible heuristic for route finding — 路徑問題的 admissible 啟發函數
IDA*IDA*Iterative deepening with f-cost cutoff — 以 f-cost 為 cutoff 的迭代加深
Effective branching factor (b*)有效分支因子Average branching factor measuring heuristic quality — 衡量啟發函數品質的平均分支因子
Dominates支配h2(n) ≥ h1(n) for all n — 對所有 n 有 h2(n) ≥ h1(n)
Manhattan distance曼哈頓距離Horizontal + vertical distance — 橫向加直向距離
Relaxed problem放寬問題A problem with fewer restrictions on operators — 對動作限制較少的問題
Local search局部搜尋Keeps only a current state — 只保留目前狀態
Hill-climbing爬山法Moves to the best neighbour — 移到最佳鄰居
Local maximum局部最大值Peak lower than the global maximum — 低於全域最大的山峰
Ridge山脊Narrow rising line causing oscillation — 造成來回震盪的窄長上升帶
Plateau / shoulder平原 / 肩部Flat region of the evaluation function — 評估函數持平的區域
Random-restart hill-climbing隨機重啟爬山法Repeat from random starts, keep the best — 從隨機起點重複,保留最佳
Local beam search局部束搜尋Keeps k states, picks best k of m·k successors — 保留 k 個 state,從 m·k 個後繼挑最好的 k 個
Genetic algorithm (GA)遺傳演算法Population search with crossover and mutation — 用 crossover 與 mutation 的族群搜尋
Fitness適應度Goodness of an individual — 個體的好壞
Crossover交配Combine two parents at a random point — 在隨機切點結合兩個 parent
Mutation突變Random small change of a state — 對 state 做隨機小改變

Ch5 CSP

Term中文Meaning 意思
Constraint satisfaction problem (CSP)約束滿足問題Variables, domains and constraints — 變數、domain 與 constraints
Domain值域Possible values of a variable — 變數的可能值
Constraint約束Allowed combinations of values — 允許的值組合
Consistent assignment一致指派Violates no constraint — 不違反任何 constraint
Complete assignment完整指派Every variable has a value — 每個變數都有值
Constraint graph約束圖Nodes = variables, arcs = constraints — 節點 = 變數,弧 = constraint
Unary / binary constraint一元 / 二元約束Involves one / two variables — 涉及一個 / 兩個變數
Backtracking search回溯搜尋DFS that assigns one variable at a time — 一次指派一個變數的 DFS
MRV最少剩餘值Fewest legal values first — 先選合法值最少的變數
Degree heuristic度啟發法Most constraints on unassigned variables — 牽涉最多未指派變數的 constraint
Least-constraining value最少約束值Value that leaves most options — 讓鄰居保留最多選擇的值
Forward checking (FC)前向檢查Prune neighbours' domains after assignment — 指派後修剪鄰居的 domain
Arc consistency (AC)弧一致性Every value has a compatible partner across an arc — 每個值在弧另一端都有相容的值
Min-conflicts最少衝突Local-search value choice with fewest conflicts — 衝突最少的 local-search 選值
Tree decomposition樹分解Group variables into subproblems arranged as a tree — 把變數分成排成樹狀的子問題
Mega-variable超級變數A subproblem treated as one variable — 被當成一個變數的子問題
