Section A — Model answers
Section A——參考答案

EN: (a) S: f = 0 + 7 = 7. Expand S → A (2 + 6 = 8), B (3 + 5 = 8).
Tie A/B: expand A → C: g = 5, f = 9. Frontier: B 8, C 9.
Expand B → C via B: g = 4, f = 8 (better than 9), D: g = 7, f = 9. Frontier: C 8, D 9.
Expand C → G: g = 9, f = 9. Frontier: D 9, G 9.
Tie D/G: expand D → G via D: g = 9, f = 9 (no improvement).
Expand G: goal. Path S–B–C–G, cost 3 + 1 + 5 = 9 (S–B–D–G also costs 9). The goal is accepted only when it is selected for expansion.
中文：(a) S:f = 0 + 7 = 7。展開 S → A(2 + 6 = 8)、B(3 + 5 = 8)。
A/B 同分:展開 A → C:g = 5、f = 9。Frontier:B 8、C 9。
展開 B → 經 B 到 C:g = 4、f = 8(比 9 好);D:g = 7、f = 9。Frontier:C 8、D 9。
展開 C → G:g = 9、f = 9。Frontier:D 9、G 9。
D/G 同分:展開 D → 經 D 到 G:g = 9、f = 9(沒有改善)。
展開 G:是 goal。路徑 S–B–C–G,成本 3 + 1 + 5 = 9(S–B–D–G 也是 9)。Goal 要在被選出展開時才接受。

EN: (b) Admissible means h(n) ≤ true cost for every n: S 7 ≤ 9, A 6 ≤ 8, B 5 ≤ 6, C 4 ≤ 5, D 2 ≤ 2, G 0 ≤ 0. All hold, so h is admissible.
With h(B) = 8: 8 > 6, so h overestimates and is not admissible. Then f(B) = 3 + 8 = 11. A* expands S, A (f 8), C via A (g 5, f 9), then G via C (g 10, f 10) is selected before B (11), so A* returns S–A–C–G with cost 10, but the optimal cost is 9. An overestimate can make A* miss the optimal path.
中文：(b) Admissible 即對每個 n 都有 h(n) ≤ 真實成本:S 7 ≤ 9、A 6 ≤ 8、B 5 ≤ 6、C 4 ≤ 5、D 2 ≤ 2、G 0 ≤ 0。全部成立,所以 h 是 admissible。
若 h(B) = 8:8 > 6,h 高估了,不是 admissible。此時 f(B) = 3 + 8 = 11。A* 展開 S、A(f 8)、經 A 到 C(g 5、f 9),然後經 C 到 G(g 10、f 10)會在 B(11)之前被選出,所以 A* 回傳 S–A–C–G,成本 10,但最佳成本是 9。高估會讓 A* 錯過最佳路徑。

EN: (c) (i) Degree heuristic: all variables have 3 values so MRV cannot decide; SA has degree 5, the highest, so choose SA.
(ii) SA = R → FC removes R from WA, NT, Q, NSW, V: each {G, B}.
(iii) Q = G → NT loses G → {B}; NSW loses G → {B}. WA {G, B}, V {G, B}.
(iv) MRV: NT and NSW have 1 value. NT = B → WA loses B → {G}. NSW = B → V loses B → {G}. WA = G, V = G.
Solution: SA = R, Q = G, NT = B, NSW = B, WA = G, V = G. T is independent (no constraints), so it is a separate sub-problem: any colour works. This reduces the work from O(d^n) to O(d^(n−1)) plus a constant.
中文：(c) (i) Degree heuristic:所有變數都有 3 個值,MRV 分不出高下;SA 的 degree = 5 最高,所以先選 SA。
(ii) SA = R → FC 把 R 從 WA、NT、Q、NSW、V 刪掉:各剩 {G, B}。
(iii) Q = G → NT 刪掉 G → {B};NSW 刪掉 G → {B}。WA {G, B}、V {G, B}。
(iv) MRV:NT 與 NSW 只剩 1 個值。NT = B → WA 刪掉 B → {G}。NSW = B → V 刪掉 B → {G}。WA = G、V = G。
解:SA = R、Q = G、NT = B、NSW = B、WA = G、V = G。T 獨立(沒有 constraint),是另一個子問題:任何顏色都可以。工作量由 O(d^n) 降為 O(d^(n−1)) 加一個常數。

EN: (d) (i) Rows (P, Q): (T,T): P∨Q true, ¬P false → KB false. (T,F): ¬P false → KB false. (F,T): P∨Q true, ¬P true → KB true. (F,F): P∨Q false → KB false. The only model of KB is P = F, Q = T, and Q is true in it, so KB ⊨ Q.
(ii) (1) ∀x Student(x) ⇒ ∃y (Teacher(y) ∧ Likes(x, y)). (2) ∀x King(x) ⇒ ¬Commoner(x), equivalently ¬∃x (King(x) ∧ Commoner(x)). Use ⇒ with ∀ and ∧ with ∃.
中文：(d) (i) 各列 (P, Q):(T,T):P∨Q 為真、¬P 為假 → KB 為假。(T,F):¬P 為假 → KB 為假。(F,T):P∨Q 為真、¬P 為真 → KB 為真。(F,F):P∨Q 為假 → KB 為假。KB 唯一的 model 是 P = F、Q = T,其中 Q 為真,所以 KB ⊨ Q。
(ii) (1) ∀x Student(x) ⇒ ∃y (Teacher(y) ∧ Likes(x, y))。(2) ∀x King(x) ⇒ ¬Commoner(x),等價於 ¬∃x (King(x) ∧ Commoner(x))。∀ 配 ⇒,∃ 配 ∧。

解釋

  • 1-B (Ch1) Rational systems do not care about the method, only the correctness of the outcome, usually with maths and logic. Humanly systems are unreliable. — Rational 系統不在乎方法,只在乎結果正確,通常用數學與邏輯。人類式系統不可靠。
  • 2-B (Ch1) NLP converts English to data structures; knowledge representation stores/retrieves data as knowledge; reasoning concludes answers; ML learns from data. — NLP:英文↔資料結構;知識表示:資料↔知識以便存取;推理:由已有知識得出結論;ML:從資料學習。
  • 3-B (Ch1) The lecture lists logistics planning and scheduling for transportation, reducing planning time from weeks to hours. — 講義:運輸的自動物流規劃與排程,把規劃時間從數週縮到數小時。
  • 4-A (Ch1) AI aims to replace/alleviate human labour. For intelligence-intensive jobs humans still do better than AI. — AI 的目的是取代/減輕人類勞力;智力密集的工作人類目前仍較好。
  • 5-B (Ch1) Building humanly AI needs a precise theory of mind, which we do not have. — 要做人類式 AI 需要精確的心智理論,但我們沒有。
  • 6-B (Ch2) 2 squares × 10,000 steps = 20,000. — 2 格 × 10,000 步 = 20,000。
  • 7-A (Ch2) Each perception-action pair is independent. Chess, games and assembly are sequential. — 每一對感知與行動彼此獨立。棋類、遊戲、組裝是 sequential。
  • 8-B (Ch2) Chess has two competing agents. Crossword is single-agent; taxi collision avoidance is cooperative. — 西洋棋有兩個競爭的 agent。填字是單一 agent;taxi 避撞是合作式。
  • 9-B (Ch2) A table covers every combination of percepts of any length, which is infinite, so we use an agent program. — 查表要涵蓋任何長度的感知組合,是無限的,所以改用 agent program。
  • 10-B (Ch2) It adjusts its decisions from feedback so it does better on the same problem in future. — 它根據回饋調整決策,下次做同樣的問題時表現更好。
  • 11-C (Ch3) Optimal = lowest path cost, not necessarily the shallowest. — Optimal = 路徑成本最低,不一定最淺。
  • 12-B (Ch3) Incremental starts from an empty board and adds queens. Complete-state starts with all 8 queens and moves attacked ones. — Incremental 從空盤開始加皇后;complete-state 從 8 個皇后開始再移動被攻擊的皇后。
  • 13-B (Ch3) A goal beyond the limit is never reached, so DLS is not complete when l < d. — goal 在限制之外就永遠到不了,所以 l < d 時 DLS 不 complete。

  • 17-B (Ch4) N = 1 + b* + (b*)^2 + … + (b*)^d. A smaller b* means a smaller N. — N = 1 + b* + (b*)² + … + (b*)^d。b* 越小,N 越小。
  • 18-A (Ch4) Fewer restrictions can only make the solution cheaper, so it never overestimates the original cost. — 限制越少,解只會更便宜,所以不會高估原問題成本。
  • 19-B (Ch4) The max of admissible heuristics is admissible and dominates each one; the computer decides at run time. — 多個 admissible 啟發函數的最大值仍 admissible 且 dominates 各個;由電腦在執行時決定。
  • 20-B (Ch4) Local search keeps only the current state. Theoretically incomplete and not optimal, but works well in practice. — 只保留目前狀態。理論上 incomplete 且不 optimal,但實務上表現不錯。
  • 21-A (Ch5) Dom(SA) becomes {red, blue}. This also reduces the O(d^n) search. — Dom(SA) 變成 {red, blue},同時縮小 O(d^n) 的搜尋空間。
