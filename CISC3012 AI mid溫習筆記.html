1Chapter 1：What is AI?

例題 1.1 常考 Why do we need AI? Where can AI be applied?
題目：Why do we need to use AI? Where can AI be applied?
解題思路：先答「為什麼需要」：勞動力老化、成本、安全／危險、專業性。再答「應用範圍」：AI 應用沒有限制，但能力有限。最後補充：主要取代 labour-intensive jobs，智力密集工作人類仍較強。
English Answer：
We need AI mainly to replace or alleviate human labour, especially labour-intensive jobs. AI can learn directly from data, such as a decision tree or a neural network. However, AI has a limitation in capability: it can only reach a certain level of human intelligence. For intelligence-intensive jobs, such as a system analyst, humans still outperform AI.

AI has no limitation in application. It can be applied to almost any field, such as healthcare, finance, transportation, education, manufacturing, customer service, entertainment, and security.
例題 1.2 核心 AI 四種定義
題目：What are the two dimensions of AI definition? Which one is most promising?
解題思路：兩個維度：Thought vs. Behavior；Human-like vs. Rational。四格：Thinking Humanly、Thinking Rationally、Acting Humanly、Acting Rationally。最有前景：Acting Rationally → Rational Agent。
English Answer：
The two dimensions are Thought vs. Behavior and Human-like vs. Rational / Ideal. These give four categories: Thinking Humanly, Thinking Rationally, Acting Humanly, and Acting Rationally.

The most promising one is Acting Rationally, which leads to the Rational Agent. A rational system does not care about the method used; it only cares whether the outcome is correct. It relies on mathematical and logical models, which makes it more reliable than imitating sometimes irrational human behaviour.

Behavior 行為Acting HumanlyActing Rationally
例題 1.3 常考 Turing Test 圖靈測試
題目：What is the Turing Test? What cognitive tasks does it require?
解題思路：Turing Test 判斷 Acting Humanly。用文字溝通，分不出人還是電腦，就算有智能行為。四能力：NLP、Knowledge representation、Automated reasoning、Machine learning。Total Turing Test 加：Computer vision、Robotics。
English Answer：
The Turing Test is a test for Acting Humanly. A human questioner communicates via text with an unseen respondent. If the questioner cannot reliably tell whether the respondent is a human or a computer, the computer is considered to behave intelligently.

It requires four cognitive tasks: natural language processing, knowledge representation, automated reasoning, and machine learning. The Total Turing Test adds computer vision and robotics.

Conclusion: building a truly humanly AI system requires a precise theory of mind, which we do not have, so it is currently impossible.
例題 1.4 AI 風險
題目：What are the risks of AI?
解題思路：Fake news / deepfake、reliability、misuse、adversarial examples、就業挑戰。強調 AI 目的是取代或減輕人類勞動，不是完全取代人類。
English Answer：
Risks include fake news generation, reliability and misuse issues, and challenges to human labour. For example, deepfake voices have been used in scams, and adversarial stickers can fool a DNN into reading a stop sign as "speed limit 45". AI's purpose is to replace or alleviate human labour, especially labour-intensive jobs, not to completely replace humans.
例題 1.5 AI vs Traditional Algorithm
題目：What is the difference between AI and a traditional algorithm?
解題思路：傳統演算法由人類設計，人不懂的問題演算法也解不了。AI 直接從資料學習（decision tree / neural network），只要有資料，不需要人完全理解問題也能解決。
English Answer：
A traditional computer program (algorithm/logic) is designed by humans—if a human cannot understand or solve a problem, the algorithm cannot either. An AI program learns directly from data, such as a decision tree or a neural network. As long as data is available, the problem can be solved even without full human understanding.

2Chapter 2：Intelligent Agents

例題 2.1 常考 真空吸塵機世界
題目：Describe the vacuum cleaner world. What are its percepts and actions? What four factors determine rationality?
解題思路：Percepts：在哪個方格、乾淨或污糟。Actions：Left, Right, Suck, NoOp。理性四要素：Performance measure、Prior knowledge、Actions、Percept sequence。
English Answer：
The vacuum cleaner agent perceives which square it is in (A or B) and whether it is clean or dirty. Its actions are Move Left, Move Right, Suck, and NoOp.

Rationality depends on four factors: the performance measure, the agent's prior knowledge of the environment, the actions the agent can perform, and the agent's percept sequence up to now (memory).

例題 2.4 常考 五種 Agent
題目：List and explain the five types of agent programs.
解題思路：Simple reflex → Model-based reflex → Goal-based → Utility-based → Learning。每種記住：核心、適用環境、備註。
English Answer：
Simple reflex agents use if-then condition-action rules. They are efficient but narrow, and only work in fully observable environments.

Model-based reflex agents maintain an internal state for partially observable environments. They require knowledge of how the world evolves and how the agent's actions affect the world.

Goal-based agents choose actions based on the current state, percept, and a goal. They are less efficient than reflex agents and motivate search.

Utility-based agents use a utility function mapping a state to a real number. Utility helps trade off conflicting goals and choose among options.

Learning agents learn from environmental feedback and adjust decisions over time. They require machine learning techniques.

3Chapter 3：Rational Agent by Searching

例題 3.1 常考 Well-defined Problem 四組件
題目：What are the four components of a well-defined problem? Give examples.
解題思路：Initial state、Successor function/Actions、Goal test、Path cost function g。Solution = path to goal。Optimal solution = lowest path cost。
English Answer：
A well-defined problem has four components: initial state, successor function / actions, goal test, and path cost function g.

A solution is a path from the initial state to a state satisfying the goal test. An optimal solution is the solution with the lowest path cost among all solutions.

例題 3.2 核心 Search Strategy 比較
題目：Compare BFS, Uniform-cost, DFS, DLS, IDS, and Bidirectional search.
解題思路：四個評價標準：Completeness、Optimality、Time complexity、Space complexity。記住每種策略的 expansion order 和特點。
English Answer：
BFS: FIFO, expands shallowest first. Complete. Optimal if path cost is non-decreasing with depth. Time/space explode if branching factor is large.

Uniform-cost search: expands the node with lowest path cost g(n). Complete and optimal. Not suitable for negative-cost actions.

DFS: LIFO, goes to deepest level first. Not complete (may loop), not optimal. Lower time/space complexity. PROLOG's backtracking is this type.

DLS: DFS with a predefined max depth d. Complete (bounded tree), not optimal. Hard to choose a good d.

IDS: repeats DLS with d = 0, 1, 2, ... Complete and optimal if step cost = 1. Combines DFS's space efficiency with BFS's completeness/optimality.

ILS: like IDS but limits by path cost instead of depth. Saves memory but costs more computation.

Bidirectional search: simultaneous forward and backward search, meeting in the middle. Difficult because backward search needs reversible actions and there may be many goal states.

例題 3.3 常考 避免 Repeated States
題目：How to avoid repeated states? What is a closed list?
解題思路：三種方法，難度遞增：不返回 parent、不產生 cycle、用 closed list 檢查所有 expanded states。
English Answer：
Repeated states can cause infinite loops or inefficiency. Three approaches (increasing difficulty):
1. Do not return to the state you just came from (reject successors equal to the parent).
2. Do not create paths with cycles (reject successors equal to any ancestor).
3. Do not generate any state that has already been generated—check against all expanded states, not just ancestors. Uses a closed list, a set storing every expanded node. If the current node matches one in the closed list, discard it.
例題 3.4 常考 Partial Information 三類問題
題目：What are the three types of problems with partial information?
解題思路：Sensorless / Conformant（無 sensors，initial state 未知，用 belief states）；Contingency / Nondeterministic（action effects 不確定，要 search, execute, search, execute）；Exploration（states 和 action effects 都未知，要實驗，有風險）。
English Answer：
Sensorless / Conformant problems: no sensors, initial state unknown. Search over a set of possible initial states, called belief states.

Contingency / Nondeterministic problems: action effects are uncertain. Build a tree of possible outcomes. The agent must interleave "search, execute, search, execute…" rather than search once then execute.

Exploration problems: both states and action effects are unknown. The agent must experiment (with risk of damage). If it survives, it learns the environment for future use.
例題 3.5 Search Tree 術語
題目：Define expanding, leaf node, fringe, and the five components of a node.
解題思路：Expanding = 套用 successor function；Leaf node = 無 successors 或未 expand；Fringe = 已生成但未 expand 的 leaf nodes；Node 五要素：STATE, PARENT-NODE, ACTION, PATH-COST g(n), DEPTH。
English Answer：
Expanding: applying the successor function to a state, generating a new set of states.
Leaf node: a state with no successors (a goal), or one not yet expanded.
Fringe: the set of generated-but-not-yet-expanded leaf nodes.
A well-defined node has five components: STATE, PARENT-NODE, ACTION, PATH-COST g(n), and DEPTH.
A queue is the data structure used to organize the fringe; every search strategy uses one (they differ in ordering).
例題 3.6 適合「先規劃再執行」的環境
題目：What environments are suitable for the "plan first, then execute" approach?
解題思路：Static、Fully observable、Discrete、Deterministic。只適用最簡單的環境。
English Answer：
This approach requires the environment to be:
Static—no need to worry about changes during formulation.
Fully observable—the agent knows its initial state.
Discrete—a finite number of actions.
Deterministic—the effect of every action is known and certain.

Therefore, it can only work on the easiest environment / problem.
