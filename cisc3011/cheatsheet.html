四、Canny 四步驟

1. 高斯平滑 → 2. 算梯度大小與方向 → 3. 非極大值抑制（讓邊變細） → 4. 雙閾值 + 連通分析（防斷線）

口訣：去雜訊 → 找邊 → 瘦身 → 補線。
三目標：good detection、good localization、minimal response（NMS 負責最後這個）。

五、直方圖均衡化標準答題格式

Part B 如果考這題，照這個順序寫，每步都有分：

  1. 寫出 N（總像素）與 L（灰階級數）
  2. 列表算 h(r)：每個灰階幾個像素
  3. 列表算 cdf(r)：累加（檢查最後 = N）
  4. 套公式 s = round((L−1)/N × cdf(r))，寫出每一級的對應值
  5. 把原圖每個像素查表換成新值，畫出新影像
  6. （加分）說明：對比增強、最大值變 L−1、直方圖不會完全平坦

六、最後叮嚀：五個最常見失分

  1. 卷積忘記翻轉核（那是相關）
  2. 平滑核忘記除以總和（亮度爆掉）
  3. Gamma 記反（γ<1 是變亮）
  4. 均衡化忘記乘 (L−1) 或乘成 L
  5. Open / Close 順序顛倒（Open 先侵蝕）
