第 1 章 · 數位影像基礎

影像在電腦裡到底長什麼樣子

📌 一句話說完 一張數位影像就是一個裝滿數字的表格，每個數字代表那一點有多亮。
本章內容
  1. 影像 = 數字矩陣
  2. 取樣與量化（必考）
  3. 容量計算（必考）
  4. 人眼的特性
  5. 考點整理

1. 影像 = 數字矩陣

先丟掉「照片」這個印象。對電腦來說，一張灰階照片就是一個表格，每格放一個數字：

影像的一小塊
121590200 141895210 162099215 1822101220
  • 每一格叫做一個 像素（pixel），是 picture element 的縮寫。
  • 數字叫做強度（intensity）或灰階值。0 = 全黑，255 = 全白，中間是灰色。
  • 寫成數學就是一個函數 f(x, y)：給我座標，我告訴你那點多亮。
✅ 灰階圖 vs 彩色圖 灰階圖的形狀是 (高, 寬)，例如 (355, 355)。
彩色圖的形狀是 (高, 寬, 3)，多出來的 3 是 R、G、B 三個顏色通道，等於三張灰階圖疊在一起。
所以彩色圖的數字量是灰階圖的 3 倍。

這就是為什麼作業裡 img.shape 印出 (355, 355, 3)，而 img.size（總共幾個數字）是 355 × 355 × 3 = 378,075。

2. 取樣與量化

真實世界的光是連續的，電腦只能存離散的數字。要把連續變離散，需要兩個動作，這兩個最愛考，一定要分清楚：

取樣 Sampling量化 Quantization
在切什麼切空間（切成幾個像素）切亮度（分成幾級）
決定了空間解析度（幾乘幾）灰階級數（幾 bit）
不夠會怎樣馬賽克、鋸齒、細節消失偽輪廓：漸層變成一塊一塊
⚠️ 超高頻考點 考試很愛給你兩張壞掉的圖，問你是取樣不足還是量化不足。
口訣：格子變大 = 取樣問題；顏色變階梯 = 量化問題。

3. 容量計算

這是最好拿分的計算題，公式只有兩條。

L = 2b b = 幾個 bit，L = 總共有幾級灰階

8-bit 影像：L = 28 = 256 級，也就是 0 到 255（注意是 0 到 255，不是 1 到 256）。

總 bit 數 = 高 × 寬 × b × 通道數 除以 8 就是 byte，再除以 1024 是 KB
例題 1：一張 512×512 的 8-bit 灰階圖要多少 KB？

bit 數 = 512 × 512 × 8 = 2,097,152 bit
byte 數 = 2,097,152 ÷ 8 = 262,144 byte
KB = 262,144 ÷ 1024 = 256 KB

小技巧：8-bit 時「幾個像素就是幾個 byte」，512×512 = 262,144 byte，直接除 1024 就好。

例題 2：同樣 512×512，但換成 RGB 彩色，又是多少？

彩色有 3 個通道，所以 × 3：
262,144 × 3 = 786,432 byte = 768 KB（剛好是灰階的 3 倍）

例題 3：如果要 1024 級灰階，每個像素要幾 bit？

要解 2b = 1024。因為 210 = 1024，所以 b = 10 bit。

背熟：21=2、22=4、23=8、24=16、25=32、26=64、27=128、28=256、210=1024

4. 人眼的特性

這部分是概念題，不會算，但會考名詞。

名詞白話意思
Brightness adaptation
亮度適應		 人眼不是同時能看所有亮度，而是會「調整基準」。從戲院走到大太陽下會暫時看不見，就是在重新適應。
Weber's law
韋伯定律		 我們察覺亮度變化的能力，取決於比例而不是絕對差。
在很暗的地方加 10 格亮度很明顯；在很亮的地方加 10 格幾乎看不出來。
Mach band effect
馬赫帶效應		 兩塊不同灰色相接時，交界處看起來會比實際更亮／更暗。這是錯覺，數值上根本沒有這條邊。說明人眼會自己強化邊緣。
Simultaneous contrast
同時對比		 同樣一塊灰，放在黑背景上看起來比較亮，放在白背景上看起來比較暗。
💡 為什麼要學這個 因為 Weber's law 解釋了為什麼要用 Gamma 校正（第 2 章）， 也解釋了為什麼 8-bit（256 級）就夠用——再細人眼也看不出來。

5. 考點整理

✅ 本章一定要會
  1. 影像 = 矩陣；灰階 (H,W)、彩色 (H,W,3)；0=黑、255=白
  2. 取樣管空間、量化管亮度 — 以及各自不足的畫面症狀
  3. L = 2b；容量 = H×W×b×通道 ÷ 8 byte
  4. Mach band＝人眼錯覺會強化邊緣；Weber＝看比例不看絕對差

小測驗

Q1. 一張圖放大後看到一格一格的方塊，這是什麼不足？
量化不足
取樣不足
bit 數不足
對比不足
方塊 = 像素太少 = 取樣（sampling）不足，也就是空間解析度不夠。量化不足的症狀是漸層出現一圈圈的偽輪廓。
Q2. 一張 256×256 的 8-bit 灰階影像，未壓縮要多少 byte？
8,192
32,768
65,536
196,608
8-bit = 1 byte/像素，所以 256 × 256 × 1 = 65,536 byte（64 KB）。 196,608 是彩色（×3）的答案。
Q3. 關於 Mach band effect，下列何者正確？
是人眼的錯覺，實際像素值沒有那條亮／暗帶
是感光元件的雜訊造成的
是因為量化級數不足造成的
只會出現在彩色影像
Mach band 是視覺系統在邊界自行強化對比的結果，量測像素值會發現那條帶根本不存在。
