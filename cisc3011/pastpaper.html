A-1　亮度與對比（Basics）

題目：定義亮度 B(I) = 平均值、對比 C(I) = (max−min)/(max+min)。 給兩張同尺寸影像 I₁、I₂，下列何者不正確（incorrect）？

  1. 若 I₁ ≠ I₂，兩張圖的對比不同
  2. 若 I₁ ≠ I₂，兩張圖的直方圖不同
  3. 若 B(I₁) = B(I₂)，兩張圖對比相同
  4. 若 B(I₁) = B(I₂)，兩張圖的直方圖 PDF 相同
💡 怎麼想：這類題只要「找一個反例」 題目問哪個不正確。要證明一句話不正確，只要舉出一個反例就夠了， 不需要證明它永遠錯。
而且每個選項都是「A ⟹ B」的形式，反例就是：前提成立、但結論不成立的情況。
完整解答：答案是 A、B、C、D（四個全錯）

A 和 B 的反例（用同一組就好）：取兩張 1×2 的影像

I₁
0255
I₂
2550
  • 兩張圖確實不同（I₁ ≠ I₂）✓ 前提成立
  • 對比：C(I₁) = (255−0)/(255+0) = 1；C(I₂) = 1 → 對比相同 ⇒ A 說「對比不同」錯
  • 直方圖：兩張都是「一個 0、一個 255」→ 完全相同 ⇒ B 說「直方圖不同」錯

核心觀念：直方圖不記錄位置，把像素重新排列，直方圖與 max/min 都不變。

C 和 D 的反例：

I₃
100100
I₄
0200
  • 亮度：B(I₃) = 100、B(I₄) = (0+200)/2 = 100 → 相同 ✓ 前提成立
  • 對比：C(I₃) = (100−100)/(100+100) = 0；C(I₄) = (200−0)/(200+0) = 1 → 不同 ⇒ C 錯
  • 直方圖：一個是「兩個 100」、一個是「一個 0 一個 200」→ 不同 ⇒ D 錯
答案：A、B、C、D 四個全選。
這題完美示範了「全對才給分」的恐怖之處 —— 你只要少選一個就是 0 分。
記住這個結構：平均值（亮度）相同 ≠ 分布相同；分布相同 ≠ 影像相同。 資訊量由多到少：影像 → 直方圖 → 平均值，每往後一步就丟掉一些資訊，不可逆推。

A-5 ~ A-8　卷積的乘法次數

💡 怎麼想：一句口訣解決全部四題 「每個輸出像素要做幾次乘法 × 總共有幾個輸出像素」
輸出有 m × n 個像素（same 模式），所以只要算一個像素要幾次乘法，再乘 m×n 就好。
題目濾波器每像素乘法數總數答案
A-5k × kk × k = k²m × n × k²C
A-6k × 1km × n × kB
A-7k×1 然後 1×kk + k = 2k2 × m × n × kB
✅ A-7 要理解的重點：這就是「可分離」省時間的來源 直接做 k×k：m·n·k²　　拆成兩次 1D：2·m·n·k
加速倍數 = k² / (2k) = k/2。例如 k = 11 → 快約 5.5 倍。
（第一次用 k×1 掃一遍得到中間結果，再用 1×k 掃一遍，所以是「兩次」各 m·n·k。）

A-8　可分離是靠卷積的哪個性質？ → 答案 C（Associative 結合律）

因為可分離的意思是：

A ∗ (Kcol ∗ Krow) = (A ∗ Kcol) ∗ Krow

「把括號換位置還能得到同樣結果」—— 這正是結合律（associative）的定義。

其他選項為什麼不是：交換律（commutative）說的是 f∗g = g∗f（誰當核都一樣）； 分配律（distributive）說的是 f∗(g+h) = f∗g + f∗h（對加法可拆開）。兩者都不是「拆成兩次做」的依據。

A-9　Canny 如何去除假邊緣？ → 答案 A（Hysteresis）

💡 怎麼想：把 Canny 四步驟的「任務」各自對應清楚
步驟它負責解決什麼
1. 高斯平滑降低雜訊（預防假邊緣產生）
2. 算梯度找出邊緣的強度與方向
3. 非極大值抑制 NMS把粗邊變細（一條邊只留一個像素寬）
4. 雙閾值 + 連通性（Hysteresis）剔除假邊緣、同時避免真邊緣斷裂

題目問的是 removes spurious edges（去除假邊緣）。 弱邊緣若沒有連到任何強邊緣，就被判定為雜訊造成的假邊緣而刪除 —— 這是第 4 步做的事。

易混淆：NMS 不是在「刪假邊」，它是在「把真邊變細」。 如果題目問 thins the edges，答案才是 NMS。看清楚動詞！

A-10　哪個形態學運算能「打斷細橋、消除細突起」？

💡 怎麼想：這句話是課本對 Opening 的標準定義 Gonzalez 原文："Opening generally smooths the contour of an object, breaks narrow isthmuses, and eliminates thin protrusions."
題目幾乎是逐字翻譯過來的 → 正答是 C) Opening。
選項效果對不對
A) Dilation 膨脹變胖、連接斷裂、填洞✗ 和題意相反
B) Erosion 侵蝕變瘦，確實會打斷細橋、削掉突起
但同時讓整個物體都縮小		⚠️ 見下方說明
C) Opening 開運算打斷細橋、消除細突起，但大物體尺寸維持✓ 標準答案
D) Closing 閉運算填洞、接合缺口✗ 和題意相反
⚖️ 關於 B（Erosion）要不要選 嚴格說，侵蝕也會打斷細橋與消除細突起（因為 Opening 的第一步就是侵蝕）。 所以在「可複選」的規則下 B 有爭議。
我的建議：以 C 為主。理由是題目用的是課本描述 Opening 的原句， 而且 Opening 的精神是「去掉小東西但保留大物體形狀」，侵蝕沒有後半段這個性質。
如果題目改問 "shrinks objects" 或 "separates touching objects"，那才該選 Erosion。

B-1　把影像配對到濾波器（10 分）

💡 怎麼想：每種濾波器都有「一眼可辨」的視覺特徵 不要去猜，背這張特徵表，看圖對號入座即可。
濾波器處理後的樣子（一眼特徵）
Box Filter 均值整張均勻變模糊，亮度不變，邊緣糊掉
Median Filter 中位數也變平滑，但邊緣比 box 清楚； 若原圖有雜點，雜點乾淨消失
Max Filter 最大值整體變亮，亮點／白點擴大變成白斑，暗細節被吃掉
Min Filter 最小值整體變暗，暗點擴大，亮區縮小
Laplacian變成灰底 + 浮雕感的輪廓圖（有正有負，中間灰）
Sobel黑底 + 亮白邊線（梯度大小，平坦區 = 0 = 全黑）
Hough Transform❗ 輸出不是影像，而是參數空間的圖 —— 看起來完全不像原圖，通常是干擾選項
✅ 作答策略（三步）
  1. 先分兩大類：結果還「看得出是鳥」= 平滑類（Box / Median / Max / Min）； 結果變成輪廓線 = 微分類（Laplacian / Sobel）。
  2. 微分類再分：灰底浮雕 → Laplacian；黑底白線 → Sobel。
  3. 平滑類再分：明顯變亮 + 白斑擴大 → Max；明顯變暗 → Min； 純模糊 → Box；雜點消失但邊緣仍清楚 → Median。

Hough Transform 在這類配對題裡幾乎永遠是陷阱選項，因為它根本不輸出一張「處理後的照片」。
