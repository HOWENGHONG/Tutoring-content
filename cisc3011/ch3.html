第 3 章 · 直方圖

用統計圖看懂一張照片，並自動增強對比

📌 一句話說完 直方圖就是「每一種亮度各有幾個像素」的長條圖； 把它攤平就能自動增強對比，這叫直方圖均衡化。
🔥 這章最可能出 Part B 計算題 直方圖均衡化的手算是本科最經典的考題。下面的四步驟和例題請務必練到閉著眼睛也會。

1. 直方圖是什麼

把整張圖的像素倒出來，按亮度分類數一數：

h(i) = 灰階值等於 i 的像素個數 i = 0, 1, 2, …, L−1（8-bit 的話是 0~255，共 256 個格子）

程式就是這樣寫（作業 hw3 考過）：

hist = [0] * 256                  # 256 個計數器
for i in range(H):
    for j in range(W):
        hist[ img[i][j] ] += 1    # 用亮度當索引，那格 +1
✅ 三個重要性質
  1. 所有長條加起來 = 總像素數 N
  2. 直方圖丟失了位置資訊 — 把圖打亂重排，直方圖完全一樣。所以不同的圖可能有相同直方圖。
  3. 正規化直方圖 p(i) = h(i)/N，可看成「隨便抓一個像素，亮度是 i 的機率」

累積直方圖（CDF）

cdf(i) = h(0) + h(1) + … + h(i) 意思是：亮度「小於等於 i」的像素總共有幾個

性質：一路遞增不會下降，而且最後一格 cdf(L−1) 一定等於 N。這是檢查算對沒的好方法。

2. 看直方圖診斷照片

直方圖長相照片的問題
全部擠在左邊曝光不足（太暗）
全部擠在右邊曝光過度（太亮）
擠在中間窄窄一條對比太低（灰濛濛、霧感）
分散在整個範圍曝光與對比良好 ✅
左端或右端出現一根超高的柱子有像素被削掉（clipping）：暗部死黑或亮部過曝，細節救不回來
像梳子一樣一根一根有空隙影像被處理過（例如做過對比拉伸或均衡化），或是壓縮造成的
💡 為什麼均衡化後會出現「梳子狀」空隙 因為灰階是整數。均衡化會把多個原始灰階合併到同一個新值， 也會讓某些新值沒有任何像素對應（空隙）。
所以均衡化後的直方圖不會真的變成平的！這是極常考的觀念題。

3. 對比拉伸（Auto-contrast）

最簡單的增強：把目前用到的範圍 [rmin, rmax] 線性拉開到滿格 [0, L−1]。

s = (r − rmin) / (rmax − rmin) × (L − 1)

和均衡化的差別：

  • 對比拉伸是線性的，只是把範圍拉寬，直方圖形狀不變（只是變胖）。
  • 均衡化是非線性的，會根據像素多寡重新分配：像素多的地方拉開、像素少的地方壓縮。

4. 直方圖均衡化四步驟

⭐ 把這四步背起來，Part B 照著寫就有分
  1. 算直方圖 h(i)：每個亮度有幾個像素
  2. 算累積直方圖 cdf(i)：一路加上去
  3. 算對應表：s = round( (L−1)/N × cdf(r) )
  4. 查表換值：把每個像素的舊值換成對應的新值
s = round( (L−1) / N × cdf(r) ) L = 灰階級數（8-bit 時 256）、N = 總像素數、cdf(r) = 累積到 r 的像素數

這條公式在幹嘛？（理解了就不會記錯）

  • cdf(r) / N → 算出「亮度 ≤ r 的像素佔全圖幾成」，範圍 0 到 1。
  • 再乘 (L−1) → 把這個 0~1 的比例攤開到完整的 0~255 範圍。
  • round → 灰階必須是整數。
⚠️ 三個最常見的錯
  1. 忘記乘 (L−1) → 結果全部擠在 0~1，整張圖變全黑
  2. 乘成 L（256）而不是 L−1（255） → 最大值變 256，超出範圍
  3. 忘記 round → 得到小數，不是合法的灰階值
✅ 驗算技巧（考試時自我檢查） 最大的那個灰階，其 cdf 一定 = N，所以 s = round((L−1)/N × N) = L−1。
也就是說：均衡化後的最大值必定是 255（或 L−1）。算出來不是的話就是算錯了。

檢查：cdf 最後 = 25 = N ✓，最大值對應到 7 = L−1 ✓

注意這裡發生的事：原本的 5、6、7 三個灰階全部被合併成 7。 這就是為什麼均衡化後直方圖會有空隙、而且不可逆（資訊損失了）。

均衡化之後會怎樣？

  • 像素多的灰階區間 → 被拉開（對比變強，細節看得到）
  • 像素少的灰階區間 → 被壓縮甚至合併
  • 整體對比增強，標準差變大
  • 直方圖變得比較「分散」但不是完全平坦
  • 可能放大雜訊（原本看不見的雜訊被拉開後變明顯）

6. 補充：兩個延伸概念

方法做法優缺點
Adaptive HE
（局部均衡化）		 不對整張圖做，而是取一個小視窗，對視窗內做均衡化，把結果給中心像素，逐點滑過整張圖。 ✅ 局部細節更好
❌ 計算量大、會放大雜訊
Histogram Matching
（直方圖匹配／規定化）		 不是攤平，而是讓 A 圖的直方圖「長得像」B 圖的直方圖。 可做風格／色調轉移。彩色圖對 R、G、B 各通道獨立處理。

7. 考點整理

✅ 本章一定要會
  1. 直方圖定義；丟失位置資訊（不同圖可有相同直方圖）
  2. cdf 遞增、最後 = N
  3. 均衡化四步驟 + 公式 s = round((L−1)/N × cdf(r))
  4. 均衡化後最大值必為 L−1；直方圖不會完全平坦（離散造成空隙）
  5. 均衡化不可逆（灰階被合併）
  6. 對比拉伸是線性、均衡化是非線性

小測驗

Q1. 關於直方圖均衡化後的結果，何者正確？
直方圖會變成完全平坦的水平線
影像的對比一定會下降
最大灰階值會被對應到 L−1
處理後可以完全還原回原圖
最大灰階的 cdf = N，所以 s = round((L−1)/N × N) = L−1，正確。
直方圖不會完全平坦（灰階是離散的）；對比是增強；因為灰階會被合併所以不可逆。
Q2. 某 4×4 影像（N=16, L=8）中，灰階 3 的累積個數 cdf(3) = 8，則灰階 3 會被對應到？

s = round( (8−1)/16 × 8 ) = round( 7/16 × 8 ) = round(3.5) = 4。
（Python 的 round(3.5) 會給 4；考試寫 4 即可。）
Q3. 兩張完全不同的照片，有沒有可能擁有一模一樣的直方圖？
不可能，直方圖是唯一的
只有兩張圖完全相同時才可能
只有灰階圖才可能
有可能，因為直方圖不記錄像素的位置
直方圖只統計「有幾個」，完全不管在哪裡。把一張圖的像素隨意打亂重排，直方圖一模一樣，但畫面完全不同。
Q4. 一張照片的直方圖全部擠在最左邊一小段，代表？
照片太暗且對比低
照片太亮且對比低
照片對比很好
照片有雜訊
靠左 = 值小 = 暗；擠成一小段 = 用到的灰階範圍很窄 = 對比低。這正是直方圖均衡化最能發揮的情況。
