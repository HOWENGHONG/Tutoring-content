完整解答

(a)　Box filter：係數全為 1/9

203020 309030 203020

總和 = 20+30+20+30+90+30+20+30+20 = 290
輸出 = 290 / 9 = 32.22

(a) 下列 3×3 視窗，分別求中位數與平均值，並說明哪個較合理。

1210255 111314 01211

(b) 下列 5×5 影像含椒鹽雜訊，求 3×3 中位數濾波在有效區域（中間 3×3）的結果。

55555 5525555 50555 5552555 55555
完整解答

(a)

排序 9 個值：0, 10, 11, 11, 12, 12, 13, 14, 255
中位數 = 第 5 個（index = 9//2 = 4，從 0 起算）= 12

平均 = (12+10+255+11+13+14+0+12+11) / 9 = 338 / 9 = 37.56

中位數（12）比較合理。除了 255 和 0 這兩個雜訊，其餘像素都在 10~14 之間， 中位數落在這個範圍內；平均值卻被 255 拉高到 37.56，明顯偏離真實亮度。
原因：排序後極端值被排到兩端，取中間值自然就忽略了它們。

(b)　每個位置取 3×3 共 9 個值排序取中間。以中心 (2,2) 為例：
鄰域為 {5,255,5, 0,5,5, 5,5,255} → 排序 0,5,5,5,5,5,5,255,255 → 中位數 = 5

555 555 555

椒鹽雜訊被完全清除。

對照：若改用 3×3 平均濾波，同樣位置會得到 32.2、60.0、4.4 等等 —— 雜訊沒被去掉，只是被「抹開」污染了周圍的乾淨像素。

B-5　Unsharp Masking / Highboost（10 分）

某一列 4 個像素，原始值與高斯模糊後的值如下：

位置P1P2P3P4
原圖 f10015020060
模糊 f̄12013017080

(a) 求 unsharp mask。(b) 求 k = 1 與 k = 3 的銳化結果（注意範圍）。(c) 說明 k 太大的後果。

完整解答

(a)　mask = 原圖 − 模糊

P1P2P3P4
mask100−120 = −20150−130 = +20200−170 = +3060−80 = −20

mask 為正 → 該點本來就比周圍亮；為負 → 本來就比周圍暗。

(b)　結果 = f + k × mask

kP1P2P3P4
k = 1100−20 = 80150+20 = 170200+30 = 23060−20 = 40
k = 3100−60 = 40150+60 = 210200+90 = 290 → 箝位 25560−60 = 0

k = 3 時 P3 算出 290 超過上限，必須 clip 成 255；P4 剛好落在 0。

(c)　k 太大的後果

  • 亮的更亮、暗的更暗 → 邊緣兩側出現過曝的白邊與死黑的黑邊，即光暈（halo / overshoot）。
  • 超出 0~255 的值被箝位 → 細節被削平、資訊永久損失（P3 和 P4 就是例子）。
  • 雜訊也屬於高頻，會被一起放大。

補充：k = 1 稱為 unsharp masking，k > 1 稱為 highboost filtering。

B-6　Sobel 梯度與邊緣方向（10 分）

5×5 影像（左半暗、右半亮）：

1010106060 1010106060 1010106060 1010106060 1010106060

(a) 求位置 (2,2) 的 Gx、Gy、梯度大小與方向。(b) 判斷邊緣走向。 (c) 位置 (2,3) 也算一次，並說明觀察到的現象與 Canny 的哪個步驟有關。

完整解答

Sobel 遮罩（以相關方式套用，不翻轉）
Gx = [[−1,0,1],[−2,0,2],[−1,0,1]]　　Gy = [[−1,−2,−1],[0,0,0],[1,2,1]]

(a)　位置 (2,2)，鄰域為：

101060 101060 101060

Gx = [(−1)(10) + 0 + (1)(60)] + [(−2)(10) + 0 + (2)(60)] + [(−1)(10) + 0 + (1)(60)]
= (−10+60) + (−20+120) + (−10+60) = 50 + 100 + 50 = 200

Gy = [(−1)(10) + (−2)(10) + (−1)(60)] + 0 + [(1)(10) + (2)(10) + (1)(60)]
= (−10−20−60) + (10+20+60) = −90 + 90 = 0

梯度大小 |∇f| = √(200² + 0²) = 200
梯度方向 θ = tan⁻¹(0 / 200) = 0°（指向水平、往右）

(b)　邊緣走向
梯度方向是 0°（水平），而邊緣永遠垂直於梯度， 所以這裡的邊緣是一條垂直線。
這與影像相符：左邊三行是 10、右邊兩行是 60，分界線確實是垂直的。✓

(c)　位置 (2,3)，鄰域為 [[10,60,60],[10,60,60],[10,60,60]]：
Gx = (−10+60) + (−20+120) + (−10+60) = 200，Gy = 0，|∇f| = 200

觀察到的現象：第 2 行和第 3 行都有很強的回應（都是 200）， 也就是說一條邊緣產生了兩個像素寬的反應 —— 邊緣變「粗」了。
對應的 Canny 步驟：非極大值抑制（Non-Maximum Suppression, NMS）。 NMS 沿著梯度方向比較，只保留局部最大值，把邊緣細化成單像素寬， 這正是 Canny 三大目標中「minimal response（一條邊只回應一次）」的來源。

B-7　Laplacian 與零交越（10 分）

(a) 一維訊號 f = [10, 10, 10, 10, 50, 50, 50, 50]，用一維 Laplacian 核 [1, −2, 1] 計算 （只需計算邊界以內的位置），並指出邊緣位置。

(b) 用 4-鄰域 Laplacian [[0,1,0],[1,−4,1],[0,1,0]] 計算下列兩個 3×3 區域中心的回應，並解釋結果。

孤立亮點
101010105010101010
平坦區域
303030303030303030
完整解答

(a)　每個位置計算 f(i−1) − 2f(i) + f(i+1)：

i計算結果
110 − 2(10) + 100
210 − 2(10) + 100
310 − 2(10) + 50+40
410 − 2(50) + 50−40
550 − 2(50) + 500
650 − 2(50) + 500

邊緣位置：結果在 i = 3（+40）與 i = 4（−40）之間由正轉負， 發生零交越（zero-crossing），所以邊緣就位在 i = 3 與 4 之間 —— 與原訊號由 10 跳到 50 的位置吻合 ✓

重點對比：一階導數在邊緣處出現峰值， 二階導數（Laplacian）在邊緣處穿越零點。所以用 Laplacian 找邊緣是找「零交越」，不是找最大值。

(b)　孤立亮點：回應 = (10 + 10 + 10 + 10) − 4(50) = 40 − 200 = −160
平坦區域：回應 = (30 + 30 + 30 + 30) − 4(30) = 120 − 120 = 0

解釋：

  • 平坦區域回應為 0，因為 Laplacian 核的係數總和為 0，常數區域必定被抵銷。
  • 孤立亮點產生很大的絕對值回應（−160），代表 Laplacian 對孤立點與雜訊極度敏感 （二階導數比一階更敏感）。
  • 這就是為什麼實務上要先做高斯平滑，合起來稱為 LoG（Laplacian of Gaussian）。

B-8　形態學運算（10 分）

以下 8×8 二值影像 A（1 = 前景），結構元 B 為 3×3 全 1、原點在中心。 影像外視為 0。

00000000 0000 0000 0000 0000 00000000 0000000 00000000

（黑格 = 前景 1：一個 4×4 方塊，加上右下角一個孤立雜點）

(a) 求侵蝕 A⊖B 與膨脹 A⊕B。(b) 求 Opening 與 Closing，並說明各自的作用。 (c) 寫出內邊界、外邊界與形態學梯度的公式與關係。

完整解答

(a)(i) 侵蝕：只有「3×3 鄰域全部為 1」的位置才保留。
4×4 方塊中，只有中間 2×2 的四個點符合；孤立雜點周圍都是 0 → 消失。

········ ········ ······ ······ ········ ········ ········ ········

面積：17 → 4

(a)(ii) 膨脹：鄰域內只要有一個 1 就變 1。方塊往外長一圈、雜點變成 3×3。

·· ·· ·· ·· ·· ····· ·····

面積：17 → 44

(b)(i) Opening = 侵蝕 → 膨脹：把 (a)(i) 的 2×2 再膨脹， 完整還原成原本的 4×4 方塊，但孤立雜點不會回來。

········ ···· ···· ···· ···· ········ ········ ········

面積 = 16（＝原本 17 減掉那一個雜點）
作用：去除比結構元小的前景雜點，同時保持大物體的大小與形狀。

(b)(ii) Closing = 膨脹 → 侵蝕：這張圖沒有洞也沒有缺口， 所以結果與原圖完全相同（面積 17，雜點仍在）。

補充對照（很好的加分說明）：若把方塊中間挖掉一個像素變成一個洞， Closing 會把洞補起來，還原成完整的 4×4 方塊； 而此時若改做 Opening，整個方塊反而會完全消失—— 因為每個 3×3 視窗都會碰到那個洞，侵蝕後一個點都不剩。
這說明：Opening 去白點、Closing 補黑洞，兩者不可互換。

(c)　邊界公式

內邊界 = A − erode(A)　　外邊界 = dilate(A) − A　　形態學梯度 = dilate(A) − erode(A)

以本題為例：內邊界 = 13 個像素、外邊界 = 27 個像素、 梯度 = 40 個像素。

關係：13 + 27 = 40，亦即形態學梯度 = 內邊界 ∪ 外邊界 （兩者不重疊，一個在物體內、一個在物體外），所以梯度得到的輪廓最粗。

B-9　Gamma 轉換（10 分）

8-bit 影像（L = 256），取 c = 1。

(a) 對 r = 50、100、200，分別求 γ = 0.5 與 γ = 2.0 的輸出值。
(b) 說明兩種 γ 分別讓影像變亮還是變暗，並解釋原因。
(c) 若直接把 r = 100 代入 r2 而不做正規化，會發生什麼問題？

完整解答

(a)　正確步驟：先正規化 → 取次方 → 乘回 255

s = 255 × ( r / 255 )γ
rr/255γ = 0.5 → sγ = 2.0 → s
500.1960.1960.5 = 0.443 → 1130.196² = 0.038 → 10
1000.3920.3920.5 = 0.626 → 1600.392² = 0.154 → 39
2000.7840.7840.5 = 0.886 → 2260.784² = 0.615 → 157

(b)　γ = 0.5 → 變亮（50→113、100→160、200→226，全部變大）
γ = 2.0 → 變暗（50→10、100→39、200→157，全部變小）

原因：正規化後的值落在 0~1 之間。對 0~1 的小數而言， 次方越大結果越小（例如 0.5² = 0.25 變小了）， 次方小於 1 則結果變大（例如 √0.25 = 0.5 變大了）。 所以 γ < 1 變亮、γ > 1 變暗。

另外觀察：暗部（r=50）變化幅度比亮部（r=200）大得多， 這正好符合人眼對暗部較敏感的特性（Weber's law），也是 Gamma 校正的用意。

(c)　100² = 10,000，遠遠超過 8-bit 的上限 255。

  • 若有做箝位 → 幾乎所有像素都被夾成 255，整張圖變全白，細節全失。
  • 若沒做箝位、又用 uint8 儲存 → 會溢位繞回（10000 mod 256 = 16）， 得到完全錯誤且混亂的影像。

結論：冪次轉換前一定要先正規化到 0~1。

B-10　Alpha 混合與羽化（10 分）

前景 F = 240、背景 B = 40。

(a) 寫出 alpha 混合公式，並求 α = 0、0.25、0.5、0.75、1 時的結果。
(b) 解釋為什麼公式用 (1 − α) 而不是其他權重。
(c) 說明過渡帶（window size）太窄與太寬各會有什麼問題。

完整解答

(a)

I = α · F + (1 − α) · B
α計算I
00(240) + 1(40)40（完全是背景）
0.250.25(240) + 0.75(40) = 60 + 3090
0.50.5(240) + 0.5(40) = 120 + 20140
0.750.75(240) + 0.25(40) = 180 + 10190
11(240) + 0(40)240（完全是前景）

可以看到 α 從 0 到 1，結果從背景值平滑過渡到前景值。

(b)　因為兩個權重加起來必須等於 1（α + (1−α) = 1），這樣才能保證：

  • 結果一定落在 F 與 B 之間，不會超出合法範圍；
  • 當兩張圖亮度相同時（F = B），混合後亮度維持不變。

若寫成 α·F + α·B，當 α = 1 時會變成 F + B = 280 → 溢位爆掉。

(c)

過渡帶問題原因
太窄看得到明顯接縫（seam）α 從 1 瞬間掉到 0，亮度不連續
太寬出現鬼影（ghosting），物體看起來半透明兩張圖在大範圍內同時以中間比例疊加

經驗法則：過渡帶寬度約取最大明顯特徵的尺寸。
更好的做法是 Pyramid blending：把影像拆成不同頻率層， 低頻用寬過渡、高頻用窄過渡，就能同時避免接縫與鬼影。

B-11　取樣、量化與容量（10 分）

(a) 一張 512×512 的 8-bit 灰階影像，未壓縮需要多少 byte？多少 KB？
(b) 同尺寸的 RGB 彩色影像呢？
(c) 一張 1024×768 的 10-bit 灰階影像需要多少 KB？共有幾級灰階？
(d) 說明取樣不足與量化不足分別造成什麼視覺問題。

完整解答

(a)　總 bit = 512 × 512 × 8 = 2,097,152 bit
byte = 2,097,152 ÷ 8 = 262,144 byte
KB = 262,144 ÷ 1024 = 256 KB

小技巧：8-bit 時 1 像素 = 1 byte，所以直接 512×512 = 262,144 byte。

(b)　RGB 有 3 個通道：262,144 × 3 = 786,432 byte = 768 KB（正好 3 倍）

(c)　總 bit = 1024 × 768 × 10 = 7,864,320 bit
byte = 7,864,320 ÷ 8 = 983,040 byte
KB = 983,040 ÷ 1024 = 960 KB
灰階級數 L = 210 = 1024 級（範圍 0 ~ 1023）

(d)

切什麼不足時的視覺問題
取樣 Sampling切空間（像素數量） 畫面出現馬賽克方塊、鋸齒邊緣、細節消失
量化 Quantization切亮度（灰階級數） 平滑漸層變成一圈圈階梯，稱為偽輪廓（false contour）

B-12　Canny：NMS 與雙閾值（10 分）

某影像經 Sobel 後得到梯度大小如下，且所有點的梯度方向皆為水平（0°）：

00000 02040250 03080350 02550300 00000

(a) 依序列出 Canny 的四個步驟。(b) 對中間 3×3 區域做非極大值抑制。 (c) 取 H = 60、L = 30 做雙閾值，分類強／弱邊緣並說明最終保留哪些。

完整解答

(a)　Canny 四步驟

  1. 高斯平滑 —— 先去雜訊，避免微分放大雜訊
  2. 計算梯度大小與方向 —— 通常用 Sobel 求 Gx、Gy
  3. 非極大值抑制（NMS） —— 沿梯度方向比較，邊緣細化成單像素寬
  4. 雙閾值 + 連通性分析（Hysteresis） —— 連接邊緣、去除假邊緣

(b)　NMS：梯度方向是水平，所以每個點和左右兩個鄰居比較， 只有「大於等於左右兩者」才保留，否則歸零。

位置左 / 中 / 右判斷結果
(1,1)0 / 20 / 4020 < 40，不是最大0
(1,2)20 / 40 / 2540 最大 ✓40
(1,3)40 / 25 / 025 < 40，不是最大0
(2,1)0 / 30 / 8030 < 800
(2,2)30 / 80 / 3580 最大 ✓80
(2,3)80 / 35 / 035 < 800
(3,1)0 / 25 / 5025 < 500
(3,2)25 / 50 / 3050 最大 ✓50
(3,3)50 / 30 / 030 < 500

NMS 後只剩中間一行：

00000 004000 008000 005000 00000

原本兩三個像素寬的回應，被細化成一個像素寬 ✓

(c)　雙閾值（H = 60、L = 30）

  • (2,2) = 80 > 60 → 強邊緣，直接保留
  • (1,2) = 40，介於 30 與 60 → 弱邊緣
  • (3,2) = 50，介於 30 與 60 → 弱邊緣

連通性分析：兩個弱邊緣 (1,2) 與 (3,2) 都直接與強邊緣 (2,2) 相鄰（上下相連）， 因此都被保留，最終形成一條連續的垂直邊緣線。

為什麼要用雙閾值？如果只用單一閾值：取 60 會讓 40 和 50 被刪掉， 邊緣斷斷續續（streaking）；取 30 則會讓雜訊也被當成邊緣。 雙閾值讓「夠強的核心」把「與它相連的較弱部分」一起帶進來，兼顧完整性與抗雜訊。
