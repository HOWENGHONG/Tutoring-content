Part A · 多選題（每題 5 分）

A-1. 關於取樣（sampling）與量化（quantization），下列敘述正確的有哪些？
取樣決定影像有多少灰階級數
量化不足會使平滑的漸層出現偽輪廓（false contour）
提高量化位元數可以消除馬賽克方塊
取樣不足會讓影像看起來一格一格的
正確：B、D
A 錯 —— 取樣決定的是空間解析度（幾乘幾），灰階級數是量化決定的。
C 錯 —— 馬賽克是取樣不足造成的，加大位元數（量化）沒用。
A-2. 下列哪些屬於點運算（point operation）？
影像反相 s = 255 − r
3×3 中位數濾波
Gamma 轉換 s = c·r^γ
Sobel 邊緣偵測
正確：A、C
點運算的定義是新值只取決於同一位置的舊值。
中位數濾波和 Sobel 都要讀取鄰居，屬於鄰域運算。
A-3. 關於冪次（Gamma）轉換 s = c·rγ，正確的有？
γ < 1 時影像整體變亮
γ > 1 時影像整體變亮
γ = 1 時影像會變成全黑
對 8-bit 影像運算前應先將像素正規化到 0~1，否則容易溢位
正確：A、D
0~1 之間的數，次方越大值越小 → γ>1 變暗、γ<1 變亮，所以 B 錯。
γ=1 是恆等轉換，影像不變，C 錯。
D 正確：若直接算 2551.6 會遠超 uint8 範圍。
A-4. 關於直方圖，正確的有？
從直方圖可以還原出原始影像
累積直方圖 cdf 必為遞增，且最後一項等於總像素數 N
兩張內容完全不同的影像，可能擁有相同的直方圖
直方圖擠在左側一小段，表示影像偏暗且對比低
正確：B、C、D
A 錯 —— 直方圖不記錄位置，把像素打亂重排直方圖不變，所以無法還原影像。這也正是 C 成立的原因。
A-5. 關於直方圖均衡化，正確的有？
轉換公式為 s = round((L−1)/N × cdf(r))
處理後直方圖會變成完全水平的直線
原影像中最大的灰階值，處理後會被對應到 L−1
此操作可逆，能完整還原原影像
正確：A、C
B 錯 —— 灰階是離散整數，多個灰階會被合併、某些新值沒人對應，所以直方圖呈「梳子狀」而非全平。
D 錯 —— 灰階被合併後資訊已損失，不可逆。
C 正確：最大灰階的 cdf = N，代入得 s = L−1（這是很好的驗算點）。
A-6. 關於相關（correlation）與卷積（convolution），正確的有？
卷積需要先將核旋轉 180°，相關則不用
若核本身左右上下對稱，兩者結果相同
相關滿足結合律，所以可以先合併多個核
用脈衝訊號做卷積，會得到原樣的核
正確：A、B、D
C 錯 —— 具有交換律與結合律的是卷積，不是相關。這正是實務上偏好卷積的原因。
D 正確：脈衝 ∗ 核 = 核本身（相關則會得到鏡像的核）。
A-7. 一張 200×200 的影像與 7×7 的核做運算，下列正確的有？
valid 模式輸出為 200×200
valid 模式輸出為 194×194
若結果寫在視窗中心，上下左右各有 3 格無法計算
full 模式輸出為 205×205
正確：B、C
valid = N − K + 1 = 200 − 7 + 1 = 194（A 錯，那是 same）。
無效邊界寬度 = ⌊7/2⌋ = 3，C 正確。
full = N + K − 1 = 200 + 7 − 1 = 206，所以 D 錯。
A-8. 關於濾波器，正確的有？
平滑用的核，係數總和應為 1，否則影像亮度會改變
中位數濾波是線性運算，可以寫成卷積
中位數濾波對椒鹽雜訊的效果優於平均濾波
重複施加 box filter，效果會逐漸接近高斯模糊
正確：A、C、D
B 錯 —— 中位數要排序再取中間值，無法表示為加權總和，是非線性運算。
C 正確：椒鹽是極端值，排序後被排到兩端而忽略；平均則會被拖歪。
A-9. 關於邊緣偵測，正確的有？
梯度方向與邊緣方向互相垂直
Sobel 與 Prewitt 的核係數總和皆為 0
Laplacian 運算子可同時提供邊緣強度與邊緣方向
微分會放大雜訊，因此通常先做高斯平滑
正確：A、B、D
C 錯 —— Laplacian 是各向同性（isotropic）的二階運算子，只給強度，不提供方向。 要方向必須用一階的 Sobel／Prewitt 算 θ = tan⁻¹(Gy/Gx)。
A-10. 關於形態學運算，正確的有？
Opening 是先膨脹再侵蝕
Closing 可用於填補物體內部的小洞
形態學梯度 = 膨脹結果 − 侵蝕結果
用 3×3 全 1 的 SE 侵蝕一個孤立的單像素，該點會被保留
正確：B、C
A 錯 —— Opening = 先侵蝕再膨脹（Closing 才是先膨脹）。
D 錯 —— 侵蝕要求 3×3 內全部為前景，孤立點周圍都是背景 → 會消失。

B-2. 一維卷積與相關

已知訊號 f = [1, 2, 3, 4] 與核 w = [1, 0, −1]。
(a) 求 full 相關；(b) 求 full 卷積；(c) 說明兩者結果的關係。

參考解答

(a) 相關（核不翻轉，用 [1, 0, −1]）
兩邊各補 K−1 = 2 個 0：f' = [0, 0, 1, 2, 3, 4, 0, 0]
輸出長度 = 8 − 3 + 1 = 6

  • 位置 0：(1)(0)+(0)(0)+(−1)(1) = −1
  • 位置 1：(1)(0)+(0)(1)+(−1)(2) = −2
  • 位置 2：(1)(1)+(0)(2)+(−1)(3) = −2
  • 位置 3：(1)(2)+(0)(3)+(−1)(4) = −2
  • 位置 4：(1)(3)+(0)(4)+(−1)(0) = 3
  • 位置 5：(1)(4)+(0)(0)+(−1)(0) = 4

相關結果 = [−1, −2, −2, −2, 3, 4]

(b) 卷積（核先翻轉成 [−1, 0, 1]）

  • 位置 0：(−1)(0)+(0)(0)+(1)(1) = 1
  • 位置 1：(−1)(0)+(0)(1)+(1)(2) = 2
  • 位置 2：(−1)(1)+(0)(2)+(1)(3) = 2
  • 位置 3：(−1)(2)+(0)(3)+(1)(4) = 2
  • 位置 4：(−1)(3)+(0)(4)+(1)(0) = −3
  • 位置 5：(−1)(4)+(0)(0)+(1)(0) = −4

卷積結果 = [1, 2, 2, 2, −3, −4]

(c) 關係：因為核 [1,0,−1] 是反對稱的（翻轉後正好變號）， 所以卷積結果 = 相關結果 × (−1)。
若核是對稱的（例如 [1,2,1]），兩者會完全相同。

B-3. Sobel 梯度

下列 3×3 影像區域，求中心像素的 Gx、Gy、梯度大小與方向，並說明該處邊緣的走向。

202020 202020 808080
參考解答

Sobel 核
Gx = [[−1,0,1],[−2,0,2],[−1,0,1]]　　Gy = [[−1,−2,−1],[0,0,0],[1,2,1]]

算 Gx（左右相減）：
列1：(−1)(20) + (0)(20) + (1)(20) = 0
列2：(−2)(20) + (0)(20) + (2)(20) = 0
列3：(−1)(80) + (0)(80) + (1)(80) = 0
Gx = 0（因為每一列左右都一樣，沒有水平變化）

算 Gy（上下相減）：
上排：(−1)(20) + (−2)(20) + (−1)(20) = −80
中排：0
下排：(1)(80) + (2)(80) + (1)(80) = 320
Gy = −80 + 0 + 320 = 240

梯度大小 = √(0² + 240²) = 240
梯度方向 θ = tan⁻¹(240 / 0) = 90°（指向 y 方向，即垂直方向）

邊緣走向：梯度指向垂直（90°），而邊緣垂直於梯度， 所以這裡是一條水平的邊緣 —— 和影像上半部暗（20）、下半部亮（80）的情況吻合。✓

B-4. 形態學運算

下列二值影像（1 = 前景），SE 為 3×3 全 1、原點在中心，邊界外視為 0。
求 (a) 侵蝕、(b) 膨脹、(c) Opening 的結果，並說明 Opening 的作用。

000000 011100 011100 011100 000010 000000
參考解答

(a) 侵蝕：只有「3×3 鄰域全部為 1」的位置才留下。
只有 (2,2) 這一格（3×3 方塊的正中心）符合； 右下角 (4,4) 的孤立點周圍都是 0 → 消失。

000000 000000 001000 000000 000000 000000

(b) 膨脹：3×3 鄰域內只要有一個 1，中心就變 1。
方塊往外長一圈；孤立點長成 3×3。

111100 111100 111111 111111 111111 000011

(c) Opening = 先侵蝕再膨脹：把 (a) 的結果（只剩一格）再膨脹 3×3， 得到原來的 3×3 方塊，而孤立點不會回來。

000000 011100 011100 011100 000000 000000

作用說明：Opening 去除了比 SE 小的雜點（右下角孤立點）， 同時保留了大物體的原本大小與形狀（3×3 方塊完好無損）。 這就是為什麼 Opening 常用來去除前景中的小雜訊。
