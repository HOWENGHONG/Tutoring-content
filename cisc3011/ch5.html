用「微分」找出輪廓

1. 什麼是邊緣

邊緣就是影像中亮度突然改變的位置。造成邊緣的四種原因（考過名詞題）：

  • 深度不連續（depth discontinuity）— 物體擋住後面的東西
  • 表面法線不連續（surface normal）— 物體的轉角、摺痕
  • 表面顏色不連續（surface color）— 貼紙、花紋
  • 光照不連續（illumination）— 影子邊界

2. 一階微分與梯度

連續函數的微分是斜率。影像是離散的，所以用相鄰像素相減來近似：

中央差分：f′(x) ≈ [ f(x+1) − f(x−1) ] / 2 寫成核就是 ½ × [−1, 0, 1]

影像是二維的，所以要分別對 x 和 y 微分，合起來叫梯度（gradient）：

∇f = ( ∂f/∂x , ∂f/∂y ) = ( Gx , Gy )
大小 |∇f| = √( Gx² + Gy² )　　方向 θ = tan−1( Gy / Gx ) 大小 = 邊緣有多強；方向 = 亮度變化最快的方向
⭐ 極常考的觀念 梯度方向 ⊥（垂直於）邊緣方向。
想像一條垂直的邊界線：你要感受亮度變化，必須左右走（水平方向）， 所以梯度指向水平，而邊緣本身是垂直的 —— 兩者差 90°。
💡 簡化算法 有時為了省計算，會用 |Gx| + |Gy| 近似平方根（絕對值相加）。 考試若沒特別說，用標準的平方根公式。

3. Sobel 與 Prewitt

🔥 這兩組核要背起來

Sobel（最常用）

Gx（偵測垂直邊緣）
−101 −202 −101
Gy（偵測水平邊緣）
−1−2−1 000 121

Prewitt

Gx
−101 −101 −101
Gy
−1−1−1 000 111
✅ 兩者的差別與記法 Sobel 中間那排是 2（給中心列／行更大權重，等於順便做了一點平滑），所以比較抗雜訊。
Prewitt 全部都是 1。
記法：Gx 是「左負右正」（左右相減 → 抓左右的變化 → 找垂直線）； Gy 是「上負下正」（上下相減 → 找水平線）。
兩個核的係數總和都是 0 —— 這是微分類核的共同特徵（平坦區域輸出 0）。
手算例題：求下列 3×3 區域中心的 Sobel 梯度大小與方向
101050 101050 101050
（左邊暗、右邊亮 → 有一條垂直邊緣）

算 Gx（對應位置相乘後加總）：
= (−1)(10) + (0)(10) + (1)(50)
  + (−2)(10) + (0)(10) + (2)(50)
  + (−1)(10) + (0)(10) + (1)(50)
= (−10 + 50) + (−20 + 100) + (−10 + 50)
= 40 + 80 + 40 = 160

算 Gy：
= (−1)(10) + (−2)(10) + (−1)(50)
  + 0 + 0 + 0
  + (1)(10) + (2)(10) + (1)(50)
= (−10 −20 −50) + (10 + 20 + 50) = −80 + 80 = 0

大小 = √(160² + 0²) = 160
方向 θ = tan−1(0 / 160) = 0°（指向 x 正方向，也就是水平向右）

解讀：梯度指向水平（0°），而邊緣是垂直的 —— 再次驗證「梯度 ⊥ 邊緣」。
Gy = 0 是因為上下方向完全沒有亮度變化。

4. 雜訊問題：先平滑

⚠️ 微分會放大雜訊 雜訊的特徵就是「鄰居之間差很多」，而微分正是在算差 —— 所以雜訊會被嚴重放大， 直接微分可能整張圖都是假邊緣。

解法：先用高斯平滑，再微分。

d/dx ( G ∗ f ) = ( d/dx G ) ∗ f 微分定理（Derivative Theorem）
✅ 這條公式的好處 本來要做兩次運算（先平滑、再微分），現在可以先把高斯核微分好， 得到一個「高斯的導數核」，只對影像做一次卷積就好 → 省一半時間。
這用到的是卷積的結合律。

σ 的取捨（常考的 trade-off）：

  • σ 大（平滑多）→ 雜訊少、但邊緣位置變模糊不準（定位差），細節消失
  • σ 小（平滑少）→ 定位準、細節多、但雜訊多，假邊緣多

5. 二階微分：Laplacian

一階微分在邊緣處出現峰值；二階微分則在邊緣處穿越零點（zero-crossing）。

Laplacian 核

4-鄰域版
010 1−41 010
8-鄰域版
111 1−81 111
✅ 辨認 Laplacian 核的方法 中間一個大負數，周圍都是正數，而且全部加起來 = 0。
（0+1+0+1−4+1+0+1+0 = 0 ✓）
它是各向同性（isotropic）的 —— 不管邊緣朝哪個方向都一樣敏感， 所以它只給邊緣強度，不給方向（這點和 Sobel 不同，常考）。

LoG（Laplacian of Gaussian）

Laplacian 是二階微分，對雜訊更敏感。所以一樣先平滑：先高斯模糊再做 Laplacian， 合起來叫 LoG，形狀像倒過來的墨西哥帽（Mexican hat）。 實務上常用兩個不同 σ 的高斯相減來近似，叫 DoG（Difference of Gaussians）。

6. Canny 四步驟

🔥 幾乎必考：順序不能錯
  1. 高斯平滑（Smoothing）
    先用高斯濾波去雜訊，避免雜訊被微分放大。
  2. 算梯度大小與方向（Gradient）
    通常用 Sobel 算出 Gx、Gy，再求 |∇f| 和 θ。
  3. 非極大值抑制（Non-Maximum Suppression, NMS）
    此時的邊緣很粗。沿著梯度方向比較：如果這點不是局部最大值就歸零。
    目的：把邊緣變細，變成一個像素寬。
  4. 雙閾值 + 連通性分析（Hysteresis）
    設高閾值 H 和低閾值 L：
    • > H → 強邊緣，直接保留
    • < L → 丟掉
    • 介於中間 → 弱邊緣，只有在「與某個強邊緣相連」時才保留
    目的：避免一條邊緣忽斷忽續（streaking）。
✅ 記憶口訣 平滑 → 求梯度 → 變細 → 雙閾值接起來
（去雜訊 → 找邊 → 瘦身 → 補線）

Canny 的三個設計目標

  • Good detection — 真的邊要找到，不要被雜訊騙
  • Good localization — 找到的位置要準，貼近真實邊緣
  • Minimal response — 一條邊只回應一次（這就是 NMS 在做的事）

前兩個互相衝突：平滑越多 detection 越好，但 localization 越差 —— 這個 trade-off 常考。

7. 考點整理

✅ 本章一定要會
  1. 邊緣四種成因；step / ramp / roof
  2. |∇f| = √(Gx²+Gy²)，θ = tan⁻¹(Gy/Gx)；梯度 ⊥ 邊緣
  3. Sobel 與 Prewitt 的核（Sobel 中間是 2，較抗雜訊）；係數和 = 0
  4. 微分放大雜訊 → 先高斯平滑；微分定理可省一次運算
  5. σ 大：抗雜訊但定位差；σ 小：定位準但雜訊多
  6. Laplacian：二階、找零交越、中間負周圍正、無方向資訊；LoG / DoG
  7. Canny 四步驟；NMS 讓邊變細；雙閾值防斷線

Q5. 增大高斯平滑的 σ，會有什麼結果？

σ 越大平滑越強 → 雜訊減少（detection 變好）， 但邊緣被抹糊、位置偏移 → localization 變差。這就是 Canny 提到的取捨。
