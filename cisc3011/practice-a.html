第 1 章 · 數位影像基礎

A-1. 關於數位影像的表示，正確的有？
A. 灰階影像可表示為二維函數 f(x, y)
B. 8-bit 灰階影像的像素值範圍是 1 ~ 256
C. RGB 彩色影像通常以 (高, 寬, 3) 的三維陣列表示
D. 像素值 0 代表白色
答案：A、C
A ✓ 給座標回傳亮度。
B ✗ 是 0 ~ 255（共 256 級）。
C ✓ 最後的 3 是 R、G、B。
D ✗ 0 是黑、255 是白。
A-2. 關於取樣與量化，正確的有？
A. 取樣決定影像的空間解析度
B. 量化決定灰階級數
C. 量化不足會使物體邊緣出現鋸齒狀（jagged edges）
D. 取樣不足造成的馬賽克，可藉由增加 bit 數改善
答案：A、B
A ✓ 取樣 = 切空間。B ✓ 量化 = 切亮度。
C ✗ 鋸齒是取樣不足的症狀；量化不足的症狀是偽輪廓（漸層變階梯）。 兩者別搞混。
D ✗ 馬賽克是取樣問題，要增加像素數，加 bit 數沒用。
A-3. 一張 1024×1024、12-bit 的灰階影像（未壓縮），正確的有？
A. 共有 4096 級灰階
B. 需要約 1.5 MB 儲存空間
C. 若改成 8-bit，需要約 1 MB
D. 像素值範圍是 0 ~ 4096
答案：A、B、C
A ✓ 2¹² = 4096。
B ✓ 1024×1024×12 ÷ 8 = 1,572,864 byte = 1.5 MB。
C ✓ 8-bit 時 1 像素 = 1 byte = 1 MB。
D ✗ 是 0 ~ 4095。
A-4. 關於人類視覺特性，正確的有？
A. Mach band 是視覺錯覺，實際像素值並沒有那條亮／暗帶
B. Weber's law 指出辨識亮度變化的能力取決於相對比例而非絕對差
C. 人眼可同時分辨所有亮度範圍，不需要適應過程
D. 同一塊灰色放在黑背景上看起來比放在白背景上亮
答案：A、B、D
A ✓ 視覺系統自行強化邊緣。
B ✓ 暗部加一點很明顯、亮部加同樣多看不出來。
C ✗ 需要 brightness adaptation（亮度適應）。
D ✓ 同時對比（simultaneous contrast）。
A-5. 關於彩色影像的處理，正確的有？
A. 同尺寸下，RGB 影像的資料量是灰階影像的 3 倍
B. 可以把 R、G、B 各自視為一張灰階影像分別處理
C. 課堂作法中，彩色影像的直方圖均衡化是對三個通道獨立進行
D. 一張 (480, 640, 3) 的彩色影像，其 size（元素總數）為 921,600
答案：A、B、C、D（四個全對）
A ✓ 多兩個通道。B ✓ hw3 就是這樣做。C ✓ 各通道獨立。
D ✓ 480 × 640 × 3 = 921,600。
注意：確實存在「四個選項全對」的題目 —— 不要因為「不可能全對吧」就心虛改答案。
A-6. 關於數位影像處理（DIP）與相關領域，正確的有？
A. DIP 的典型輸入是影像、輸出也是影像
B. 電腦圖學（Computer Graphics）的輸入是影像、輸出是模型
C. 電腦視覺（Computer Vision）著重從影像中取得理解或描述
D. 影像壓縮不屬於數位影像處理的範疇
答案：A、C
A ✓ 去雜訊、增強、銳化等都是影像進、影像出。
B ✗ 反了 —— 圖學是由模型／描述產生影像。
C ✓ 影像進、理解出（如辨識、偵測）。
D ✗ 影像壓縮是 DIP 的重要主題之一。
A-7. 關於電磁波譜與成像，正確的有？
A. 可見光只佔電磁波譜中很窄的一段
B. X 光的波長比可見光短
C. 紅外線的波長比紫外線短
D. 影像可以由可見光以外的波段取得（如 X 光、紅外線）
答案：A、B、D
A ✓ 約 400~700 nm，只是極小一段。
B ✓ 波長順序（短→長）：γ 射線 → X 光 → 紫外 → 可見光 → 紅外 → 微波 → 無線電。
C ✗ 反了，紅外線波長比紫外線長。
D ✓ 醫學 X 光、紅外熱像都是影像。
A-8. 關於影像擷取與感測，正確的有？
A. 成像的能量多半來自光源照射物體後的反射光
B. 感測器輸出的電訊號本身就是數位影像，不需要額外的轉換步驟
C. 薄透鏡成像滿足 1/f = u + v 的關係
D. 數位化只需要取樣，不需要量化
答案：A（只有一個正確）
A ✓ 也可能是透射（如 X 光）。
B ✗ 感測器輸出的是類比電訊號，必須再經 A/D 轉換（取樣＋量化）才是數位影像。
C ✗ 公式寫錯了，正確是 1/f = 1/u + 1/v（注意是倒數相加）。
D ✗ 兩者都要：取樣處理空間、量化處理數值。
注意：也有「只有一個正確」的題目，不要硬湊數量。
A-9. 一張影像若把空間解析度降低一半（長寬各減半），正確的有？
A. 資料量變為原本的 1/2
B. 資料量變為原本的 1/4
C. 灰階級數也會跟著減半
D. 影像細節會流失，可能出現鋸齒或馬賽克
答案：B、D
A ✗ 長寬各減半 → 像素數變 1/2 × 1/2 = 1/4。
B ✓ 同上。
C ✗ 灰階級數由量化位元數決定，與空間解析度無關。
D ✓ 取樣不足的典型症狀。
A-10. 一張影像若把量化位元數由 8-bit 降為 2-bit，正確的有？
A. 灰階級數由 256 降為 4
B. 平滑的漸層區域會出現明顯的階梯狀分界
C. 影像的長寬尺寸會變小
D. 這屬於取樣不足的問題
答案：A、B
A ✓ 2² = 4 級。
B ✓ 這就是偽輪廓（false contour）。
C ✗ 量化不影響尺寸，只影響每個像素能表示幾種亮度。
D ✗ 這是量化不足。
A-11. 關於影像檔案格式，正確的有？
A. JPEG 屬於有損壓縮
B. PNG 屬於有損壓縮
C. 有損壓縮可能在影像中留下人工痕跡（artifacts），並反映在直方圖上
D. 壓縮後的檔案大小一定等於 H × W × b ÷ 8
答案：A、C
A ✓ JPEG 用量化捨棄高頻資訊。
B ✗ PNG 是無損。
C ✓ 例如區塊效應，直方圖可能出現異常峰或空隙。
D ✗ 那是未壓縮的大小；壓縮後通常小得多。
A-12. 關於「解析度要多少才夠」，正確的有？
A. 需要多少解析度取決於影像的用途與觀看距離
B. 在細節豐富的區域，解析度不足會比在平坦區域更明顯
C. 8-bit 對所有專業領域都綽綽有餘，醫學影像也不需要更高的位元深度
D. 解析度越高一定越好，沒有任何代價
答案：A、B
A ✓ 看圖目的不同，需求不同。
B ✓ 平坦區降解析度不易察覺。
C ✗ 8-bit 對一般自然影像夠用，但醫學影像（CT、MRI）常用 12~16 bit，以保留更細的灰階層次。「所有」「都」是絕對化陷阱。
D ✗ 代價是儲存空間與計算時間大幅增加。
A-13. 關於感測器的飽和（saturation）與雜訊，正確的有？
A. 進光量過多超出感測上限時會飽和，該區域細節無法還原
B. 飽和會在直方圖最右端造成堆積
C. 光線不足時，雜訊相對訊號的比例會提高
D. 飽和與雜訊都可以用直方圖均衡化完全修復
答案：A、B、C
A ✓ 過曝資訊永久遺失。
B ✓ 全部被夾在最大值。
C ✓ 低光時 SNR 下降。
D ✗ 均衡化只是重新分配既有的值，無法把已經遺失的細節變回來， 反而可能讓雜訊更明顯。
A-14. 下列哪些屬於數位影像處理常見的應用／處理階段？
A. 影像去雜訊與影像增強
B. 影像分割與形態學處理
C. 以物理引擎模擬剛體碰撞
D. 影像壓縮與影像復原（restoration）
答案：A、B、D
A、B、D ✓ 都是 DIP 的標準階段。
C ✗ 那是物理模擬／電腦圖學的範疇，不是影像處理。

第 2 章 · 點運算與影像合成

A-15. 關於點運算（point operation），正確的有？
A. 輸出像素值只取決於同一位置的輸入像素值
B. 反相、二值化、Gamma 轉換都屬於點運算
C. 3×3 中位數濾波屬於點運算
D. 點運算會改變影像的空間解析度
答案：A、B
A ✓ 定義。B ✓ 三者都只用同位置的值。
C ✗ 要讀鄰域。D ✗ 只改亮度，尺寸不變。
A-16. 關於齊次（homogeneous）與非齊次點運算，正確的有？
A. 齊次點運算對所有像素套用相同的轉換函數
B. 非齊次點運算的輸出會取決於鄰居的值
C. 四角壓暗（vignette）屬於非齊次點運算
D. 非齊次點運算就是濾波
答案：A、C
A ✓ 例如整張 +50。
B ✗ 非齊次是指轉換函數隨位置不同，但仍只看自己那一點的值，不看鄰居。
C ✓ 轉換強度依座標而變。
D ✗ 濾波的定義是看鄰域，兩者不同。
A-17. 關於影像反相 s = 255 − r，正確的有？
A. 最亮的像素會變成最暗
B. 直方圖會左右鏡像翻轉
C. 這個操作不可逆
D. r = 0 會變成 255
答案：A、B、D
A ✓ B ✓ 線性反轉使直方圖整個翻過來。
C ✗ 可逆：再做一次就還原。真正不可逆的是均衡化。
D ✓
A-18. 關於冪次轉換 s = c · rγ，正確的有？
A. γ < 1 時影像變亮
B. γ > 1 時影像變暗
C. 對 8-bit 影像應先正規化到 0~1 再取次方
D. γ = 1 時影像會變成全黑
答案：A、B、C
A、B ✓ 0~1 的小數次方越大值越小。
C ✓ 否則溢位。
D ✗ γ=1 是恆等轉換，影像不變。
A-19. 關於 Gamma 校正的實務意義，正確的有？
A. 顯示器的輸出亮度與輸入訊號並非線性關係
B. 人眼對暗部的變化比亮部敏感，因此用非線性編碼較有效率
C. 拍攝端與顯示端都套用 γ ≈ 2.2，兩者即可互相抵銷
D. Gamma 校正屬於鄰域運算
答案：A、B
A ✓ 約 2.2 次方關係。
B ✓ Weber's law。
C ✗ 兩端都用 2.2 會疊加成 2.2 × 2.2 ≈ 4.8，影像會更暗。正確是拍攝端用 1/2.2、顯示端用 2.2，相乘才等於 1。
D ✗ 是點運算。
A-20. 關於對數轉換 s = c · log(1 + r)，正確的有？
A. 會把暗部的細節拉開
B. 會把亮部壓縮
C. 會讓整體影像變暗
D. 常用於壓縮動態範圍很大的影像
答案：A、B、D
A、B ✓ log 曲線在小輸入時斜率大、大輸入時斜率小。
C ✗ 整體是變亮（暗部被大幅提升）。
D ✓ 例如傅立葉頻譜的顯示。
A-21. 關於二值化（thresholding）與強度窗化（intensity windowing），正確的有？
A. 二值化把影像變成只有兩種值，是形態學處理的前置步驟
B. 二值化的閾值固定為 128，不需依影像調整
C. 強度窗化是把某個區間 [a, b] 拉伸到完整範圍，區間外的值被截斷
D. 二值化後仍保留原本的灰階層次
答案：A、C
A ✓ 第 6 章只處理二值圖。
B ✗ 閾值應依影像而定（例如看直方圖雙峰之間的谷底，或用 Otsu 自動求取）；固定 128 對偏亮或偏暗的影像會完全失效。
C ✓ 醫學影像常用（例如只看某個 HU 範圍）。
D ✗ 二值化後只剩兩種值，層次全部消失。
A-22. 關於多張影像平均，正確的有？
A. 可降低隨機雜訊，雜訊標準差約降為 1/√N
B. 平均 16 張，雜訊約降為原本的 1/4
C. 前提是多張影像必須對齊（內容相同、雜訊獨立）
D. 平均 N 張會使訊號本身也衰減為 1/N
答案：A、B、C
A ✓ 注意是 1/√N。B ✓ √16 = 4。
C ✓ 若物體移動了，平均只會產生殘影。
D ✗ 訊號固定，平均後不變。
A-23. 關於影像相減的應用，正確的有？
A. 可用於監視畫面的背景相減，找出移動物體
B. 可用於工業檢測，比對標準件找出瑕疵
C. 取絕對差 |I₁ − I₂| 之後，仍可分辨出是變亮還是變暗
D. 相減結果一定落在 0~255，不需要處理範圍問題
答案：A、B
A、B ✓ 經典應用。
C ✗ 取絕對值之後正負資訊就消失了，只知道「有差異」，無法分辨變亮或變暗（但好處是不會漏看）。
D ✗ 相減可能得到 −255 ~ 255，必須取絕對值或平移／箝位。
A-24. 關於 Alpha 混合 I = αF + (1−α)B，正確的有？
A. α = 1 時結果完全是前景 F
B. α = 0 時結果完全是前景 F
C. 兩個權重相加為 1，可確保亮度不會爆掉
D. 0 < α < 1 表示半透明，是柔和過渡的來源
答案：A、C、D
A ✓ 代入 α=1 得 F。
B ✗ α=0 得 B（背景）。
C ✓ 凸組合。
D ✓ 羽化就是讓 α 平滑變化。
A-25. 關於影像合成的過渡帶（window size），正確的有？
A. 過渡帶太窄會看到明顯接縫（seam）
B. 過渡帶太寬會出現鬼影（ghosting）
C. 過渡帶的理想寬度與影像的頻率內容無關
D. Pyramid blending 對不同頻率層使用不同寬度的過渡帶
答案：A、B、D
A ✓ 亮度不連續。B ✓ 大範圍半透明疊加。
C ✗ 關係很大，經驗法則取最大明顯特徵的尺寸。
D ✓ 低頻寬過渡、高頻窄過渡。
A-26. 關於用二值遮罩直接貼上（naive copy-paste）的問題，正確的有？
A. 邊界會出現生硬的接縫
B. 只要遮罩邊緣畫得夠精細，就能正確表現薄紗、煙霧等半透明物體
C. 二值遮罩能正確處理陰影這種「部分覆蓋」的情況
D. 只要遮罩畫得夠精準，就能完全解決上述所有問題
答案：A（只有一個正確）
A ✓ 二值遮罩在邊界造成亮度不連續。
B ✗ 半透明需要部分覆蓋，二值遮罩只有 0 或 1 兩種狀態，再精細也做不到。
C ✗ 同理，陰影是部分遮蔽，二值遮罩無法表現。
D ✗ 關鍵不在遮罩畫得準不準，而在於必須引入 0~1 連續的 alpha 通道。

A-58. 用 3×3 box filter 處理下列鄰域，中心輸出值為何？相關敘述正確的有？
鄰域各值：10, 20, 30 / 40, 50, 60 / 70, 80, 90
A. 輸出為 450
B. 輸出為 50
C. 輸出剛好等於中心原值，因為此鄰域是線性漸變
D. 輸出為 90
答案：B、C
總和 = 10+20+…+90 = 450，平均 = 450 / 9 = 50。
A ✗ 450 是沒有除以 9 的錯誤答案（忘記正規化）。
B ✓ C ✓ 因為數值線性遞增且對稱分布，平均正好等於中心值 50。
D ✗ 90 是鄰域最大值，不是平均。

第 5 章 · 邊緣偵測

A-59. 關於邊緣的成因，下列哪些可能在影像中形成邊緣？
A. 深度不連續（物體遮擋）
B. 表面法線不連續（物體的轉角、摺痕）
C. 光照不連續（影子的邊界）
D. 影像的儲存格式由 PNG 改為 JPEG
答案：A、B、C
A、B、C ✓ 連同表面顏色不連續，是講義列出的四大成因。
D ✗ 更換檔案格式不會產生場景中的邊緣（雖然有損壓縮可能帶來區塊假影， 但那是壓縮假影，不是邊緣的成因）。
A-60. 關於邊緣的型態，正確的有？
A. Step edge 是亮度瞬間跳變的理想邊緣
B. Ramp edge 有一段漸變過渡，較接近真實照片中的邊緣
C. Roof edge 對應細線狀的結構
D. 真實影像中的邊緣多半是完美的 step edge
答案：A、B、C
A ✓ B ✓ 因為鏡頭失焦、取樣與雜訊，真實邊緣都有過渡帶。
C ✓ 先升後降。
D ✗ 真實邊緣多為 ramp，完美 step 只是理想模型。
A-61. 關於影像梯度，正確的有？
A. 梯度大小 |∇f| = √(Gx² + Gy²)
B. 梯度方向 θ = tan⁻¹(Gy / Gx)
C. 梯度方向與邊緣方向平行
D. 一條水平邊緣，其梯度指向垂直方向
答案：A、B、D
A、B ✓ 標準公式。
C ✗ 是垂直 —— 本章最常考的觀念。
D ✓ 水平邊界只有上下有變化。
A-62. 關於離散微分的近似，正確的有？
A. 中央差分可寫成 [f(x+1) − f(x−1)] / 2
B. 中央差分對應的核是 ½ × [1, 0, 1]
C. 微分運算可以用卷積來實現
D. 離散影像無法進行微分，只能用積分近似
答案：A、C
A ✓ 用相鄰像素相減近似斜率。
B ✗ 核應為 ½ × [−1, 0, 1]（注意要有負號，是相減不是相加）。若寫成 [1, 0, 1] 就變成平滑而不是微分了。
C ✓ 所以 Sobel、Laplacian 都是卷積核。
D ✗ 可用有限差分（finite difference）來近似微分。
A-63. 關於 Sobel 與 Prewitt 運算子，正確的有？
A. Sobel 的中心列／行權重為 2，等於順便做了平滑，較抗雜訊
B. 兩者的核係數總和皆為 0
C. Gx 主要用於偵測垂直方向的邊緣
D. Prewitt 比 Sobel 更能抵抗雜訊
答案：A、B、C
A ✓ 兩者主要差別。B ✓ 平坦區回應 0。C ✓ 左負右正抓左右差異。
D ✗ 相反，Sobel 較抗雜訊。
A-64. 某像素的 Gx = 3、Gy = 4，正確的有？
A. 梯度大小為 5
B. 梯度方向約為 53.1°
C. 梯度大小為 7
D. 該點位於完全平坦的區域
答案：A、B
A ✓ √(9+16) = 5。B ✓ tan⁻¹(4/3) ≈ 53.13°。
C ✗ 7 是 |Gx|+|Gy| 的近似，題目未指定時應用標準公式。
D ✗ 平坦區梯度應為 0。
A-65. 關於雜訊與平滑，正確的有？
A. 微分運算會放大雜訊
B. 因此通常先做高斯平滑再求導數
C. 由微分定理，可先對高斯核微分，再與影像做一次卷積即可
D. σ 取得越大，邊緣定位越精準
答案：A、B、C
A ✓ 雜訊就是鄰居差異大。B ✓ C ✓ d/dx(G∗f) = (d/dx G)∗f，省一次運算。
D ✗ 相反：σ 大則抗雜訊好但定位差，這是經典 trade-off。
A-66. 關於 Laplacian 運算子，正確的有？
A. 它是二階微分運算子
B. 邊緣位置對應於其輸出的零交越（zero-crossing）
C. 它可以同時提供邊緣的強度與方向
D. 其核的中心為負值、周圍為正值，總和為 0
答案：A、B、D
A ✓ B ✓ 一階找峰值、二階找零交越。
C ✗ Laplacian 是各向同性的，不提供方向。
D ✓ 例如 [[0,1,0],[1,−4,1],[0,1,0]]。
A-67. 關於 LoG 與 DoG，正確的有？
A. LoG 是先用高斯平滑、再做 Laplacian
B. LoG 的形狀常被稱為「墨西哥帽」
C. DoG（兩個不同 σ 的高斯相減）可用來近似 LoG
D. 使用 LoG 的目的是讓 Laplacian 對雜訊更敏感
答案：A、B、C
A ✓ B ✓ 中間凹、周圍凸起的形狀。C ✓ 計算上更省。
D ✗ 目的剛好相反 —— 是要降低對雜訊的敏感度。
A-68. 關於 Canny 邊緣偵測，正確的有？
A. 第一步是高斯平滑
B. 非極大值抑制（NMS）可把邊緣細化為單像素寬
C. 雙閾值中，介於 L 與 H 的弱邊緣只有在與強邊緣相連時才保留
D. NMS 的目的是把斷裂的邊緣連接起來
答案：A、B、C
A ✓ B ✓ 對應「一條邊只回應一次」。C ✓ hysteresis 的精神。
D ✗ 連接斷裂邊緣是第 4 步做的，不是 NMS。
A-69. 關於 Canny 的三個設計目標，正確的有？
A. Good detection：對真實邊緣有回應，不被雜訊誤導
B. Good localization：偵測到的位置要接近真實邊緣位置
C. Minimal response：一條邊緣只產生一個回應
D. Detection 與 localization 之間存在取捨，無法同時達到最佳
答案：A、B、C、D（四個全對）
A、B、C ✓ 三大準則，其中 C 由 NMS 負責。
D ✓ 平滑越多 → 抗雜訊（detection）越好，但邊緣被抹糊 → 定位（localization）越差。
這題四個全對。
A-70. 關於雙閾值（hysteresis）的設定，正確的有？
A. 大於高閾值 H 的點直接判定為強邊緣
B. 小於低閾值 L 的點會被當成弱邊緣保留
C. 使用雙閾值的目的是避免邊緣斷斷續續（streaking）
D. 只要使用單一閾值，就不會有邊緣斷裂的問題
答案：A、C
A ✓
B ✗ 小於 L 的點直接捨棄，不是保留。弱邊緣是介於 L 與 H 之間的點。
C ✓
D ✗ 相反 —— 單一閾值正是造成斷裂的原因，所以才需要雙閾值。
A-71. 關於多尺度（multi-scale）邊緣，正確的有？
A. 在較細的尺度（小 σ）可偵測到更多細節邊緣
B. 在較粗的尺度（大 σ）只會保留較顯著的大結構邊緣
C. 調整閾值也會改變最終保留的邊緣數量
D. 存在一個對所有影像都最佳的固定 σ 與閾值
答案：A、B、C
A、B ✓ 這就是「邊緣有尺度性」的意思。
C ✓ 高閾值留下少而強的邊。
D ✗ 絕對化陷阱，參數需依影像與目的調整。
A-72. 關於其他邊緣運算子，正確的有？
A. Roberts 運算子使用 2×2 的核
B. Compass（羅盤）運算子使用多個方向的核，取其中最大的回應
C. 對 Sobel 的結果取閾值，可得到二值的邊緣圖
D. 所有邊緣運算子得到的結果都完全相同
答案：A、B、C
A ✓ 最小的微分核，對雜訊較敏感。
B ✓ 例如 8 個方向，哪個方向回應最大就代表邊緣方向。
C ✓ 講義中 Sobel 結果取 64 / 96 等閾值的例子。
D ✗ 不同運算子的核不同，抗雜訊能力與定位精度都不同。

第 6 章 · 形態學處理

A-73. 關於形態學運算的前提，正確的有？
A. 本章討論的運算作用於二值影像
B. 結構元（SE）的形狀會影響運算結果
C. 結構元必須是正方形
D. 灰階影像需先二值化才能套用這些運算
答案：A、B、D
A ✓ B ✓ 方形、十字、X 形結果都不同。
C ✗ 可以是任意形狀（hw6 用 15×13 的字元當 SE）。
D ✓ 第 2 章的二值化是前置步驟。
A-74. 關於結構元的原點，正確的有？
A. 原點決定運算結果要寫回輸出影像的哪個位置
B. 原點必須設在結構元中值為 1 的位置上
C. 若把原點設在非中心位置，結果會產生位移
D. 原點的位置不影響任何結果
答案：A、C
A ✓
B ✗ 原點慣例上設在中心，但不是必須 —— 它可以落在值為 0 的位置，甚至在結構元之外。
C ✓ 這正是用單點核做平移的原理。
D ✗ 影響很大，會造成整體位移。
A-75. 關於侵蝕與膨脹，正確的有？
A. 侵蝕要求 SE 覆蓋的所有位置都是前景，中心才保留
B. 膨脹只要 SE 覆蓋範圍內有任一前景，中心就變前景
C. 侵蝕可用來分離黏在一起的物體
D. 膨脹會讓物體內部的小洞變得更大
答案：A、B、C
A ✓ AND（全中）。B ✓ OR（有中就算）。C ✓ 細的連接處先斷開。
D ✗ 相反：膨脹填平小洞；讓洞變大的是侵蝕。
A-76. 用 3×3 全 1 的 SE 處理一個孤立的單一前景像素，正確的有？
A. 侵蝕後該點會消失
B. 膨脹後會變成 3×3 的方塊
C. Opening 後該點會消失
D. Closing 後該點會消失
答案：A、B、C
A ✓ 周圍都是背景，不滿足「全中」。
B ✓ 向外長一圈。
C ✓ Opening = 侵蝕→膨脹，侵蝕時已消失，膨脹救不回來。
D ✗ Closing = 膨脹→侵蝕：先變 3×3，再侵蝕回原本的單點， 所以該點仍然存在。
A-77. 關於 Opening 與 Closing，正確的有？
A. Opening = 先侵蝕再膨脹
B. Closing = 先膨脹再侵蝕
C. Opening 可去除比結構元小的前景雜點
D. Closing 後的前景面積會小於等於原圖
答案：A、B、C
A、B ✓ 順序不能反。C ✓
D ✗ 相反：closing(A) ⊇ A，面積大於等於原圖。 面積變小的是 Opening。
A-78. 關於 Opening／Closing 的性質，正確的有？
A. opening(A) ⊆ A
B. A ⊆ closing(A)
C. 兩者都具有冪等性：做第二次不會再改變結果
D. 連續做 Opening 三次，物體會持續縮小
答案：A、B、C
A、B ✓ opening ⊆ 原圖 ⊆ closing。C ✓ open(open(A)) = open(A)。
D ✗ 因為冪等性，第二次之後就不再改變。 會持續縮小的是連續做侵蝕。
A-79. 關於 Opening 與 Closing 的雜訊濾除用途，正確的有？
A. Opening 適合去除背景中的小白點
B. Closing 適合填補前景物體中的小黑洞
C. 先 Opening 再 Closing 與先 Closing 再 Opening，結果一定相同
D. Opening 與 Closing 的效果完全相同，可互相取代
答案：A、B
A ✓ B ✓ 兩者分工明確。
C ✗ 兩種順序的結果通常不同（形態學運算不可交換）。雖然「先 Opening 再 Closing」確實是常見的去雜訊組合，但不能說兩種順序等價。
D ✗ 兩者是對偶但不同的運算，絕不能互換。
A-80. 關於形態學邊界抽取，正確的有？
A. 內邊界 = A − erode(A)
B. 外邊界 = dilate(A) − A
C. 形態學梯度 = dilate(A) − erode(A)
D. 形態學梯度得到的輪廓比內邊界更細
答案：A、B、C
A ✓ 位於物體內部。B ✓ 位於物體外部。C ✓ 等於內 ∪ 外。
D ✗ 同時包含內外兩圈，所以更粗。
A-81. 關於膨脹與侵蝕的代數性質，正確的有？
A. 膨脹滿足交換律：A ⊕ B = B ⊕ A
B. 膨脹滿足結合律：(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)
C. 用 3×3 方形 SE 連續膨脹兩次，效果等同用一個 5×5 方形 SE 膨脹一次
D. 侵蝕也滿足交換律：A ⊖ B = B ⊖ A
答案：A、B、C
A、B ✓ 膨脹具有這兩個性質。
C ✓ 這是結合律的實際應用：可用小核重複達成大核效果，節省計算。
D ✗ 侵蝕不滿足交換律（影像與結構元的角色不對等）。
A-82. 關於侵蝕與膨脹的對偶性（duality），正確的有？
A. 對前景做侵蝕，相當於對背景做膨脹後再取補集
B. 對偶性表示侵蝕與膨脹的結果完全相同
C. 因為有對偶性，實作上只需寫一種運算就能推得另一種
D. 對偶性只在結構元為單一像素時成立
答案：A、C
A ✓ 形式為 (A ⊖ B)c = Ac ⊕ B̂（B̂ 為反射後的 SE）。
B ✗ 兩者結果相反（一個變瘦一個變胖），不是相同。
C ✓ 這是對偶性的實用價值。
D ✗ 對一般結構元都成立。
A-83. 關於形態學的實際應用，正確的有？
A. 可用侵蝕把黏在一起的物體（如硬幣）分開後再計數
B. 可直接用在灰階影像上，不必先二值化
C. 可用 Opening／Closing 清理二值化後殘留的雜點
D. 形態學運算可直接套用在彩色相片上做去雜訊
答案：A、C
A ✓ 講義中的 blob separation / counting coins 例子。
B ✗ 本章的運算定義在二值影像上，灰階必須先二值化。（雖然存在灰階形態學，但那不是本章範圍。）
C ✓ 非常常見的後處理。
D ✗ 本章方法針對二值影像，彩色相片必須先轉灰階並二值化。
A-84. 用形態學做字元偵測（hw6），正確的有？
A. 以目標字元當結構元去侵蝕文章，可找出該字元出現的位置
B. 偵測（侵蝕）階段應使用相關，即結構元不翻轉
C. 把字元蓋回去時若不翻轉結構元，會得到左右顛倒的鏡像字
D. 侵蝕之後，每個命中位置仍會保留完整的字元形狀
答案：A、B、C
A ✓ 只有「完全放得下」的位置會留下。
B ✓ 要找這個字而非鏡像。
C ✓ 膨脹定義內含一次反射，需用翻轉（卷積）抵銷。
D ✗ 侵蝕後每處只剩很小一塊（通常一個點），才需要膨脹蓋回去做視覺化。
A-85. 關於用卷積核做平移（hw6 第一題），正確的有？
A. 只含單一個 1、其餘為 0 的核，可使影像平移
B. 因為卷積會先翻轉核，實際位移方向與 1 在核中的位置相反直覺
C. 1 位於 3×3 核的正中央時，影像不會移動
D. 這種平移會改變影像的尺寸
答案：A、B、C
A ✓ B ✓ 這正是 hw6 容易算錯的地方 —— 務必記得翻轉。
C ✓ 恆等核。
D ✗ 用 'same' 模式時尺寸不變，只是內容平移（邊緣會補 0）。
A-86. 關於平移不變性（shift invariance），正確的有？
A. 卷積運算具有平移不變性
B. 平移不變表示：輸入平移後，輸出也會以相同量平移
C. 形態學的侵蝕與膨脹同樣具有平移不變性
D. 平移不變表示輸入平移後輸出完全不變
答案：A、B、C
A ✓ 同一個核套用在每個位置。
B ✓ 嚴格來說這稱為 shift-equivariance（等變），是本課所指的意思。
C ✓ 形態學運算也在每個位置套用相同的 SE。
D ✗ 輸出會跟著平移，而不是不變。
