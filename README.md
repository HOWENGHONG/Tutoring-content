## 關於本專案

本倉庫收錄了一套面向 **中學階段** 的自學輔導資源，涵蓋以下科目：

| 科目 | 年級 | 語言 | 主要內容 |
|------|------|------|----------|
| 數學 | 中三 | 英文 | 模擬試卷、考前重點整理 |
| 物理 | 中三 | 英文 | 電磁波、波動、完整學習套裝 |
| 化學 | 中三/中四 | 中英對照 | 結構與鍵合、MCQ 練習、結構化問題 |
| 英文 | 中一 | 英文 | 模擬試卷（共三卷，含新版） |

所有內容皆為 **單一 HTML 檔案**，無需額外依賴，開箱即用。適合學生自學、教師課堂補充，或家長輔導使用。

## 如何使用

1. **在線預覽**：點擊上方表格中的「🔗 預覽」連結，即可在瀏覽器中直接打開對應的 HTML 頁面。
2. **離線使用**：所有頁面均為**靜態網頁**，無需後端伺服器。你可直接下載 HTML 檔案，在本地瀏覽器中打開使用。
3. **自行修改**：若想調整內容，可 Fork 本倉庫，編輯對應的 HTML 檔案後重新提交。
4. **列印友善**：所有頁面均針對列印進行了優化，可直接使用瀏覽器的「列印」功能輸出為紙本試卷或筆記。

## 教學建議

| 使用場景 | 建議方式 |
|----------|----------|
| **學生自學** | 先閱讀「考前重點整理」類筆記，再使用模擬試卷進行自測。 |
| **教師備課** | 可直接使用模擬試卷作為課堂練習或測驗素材，HTML 格式方便投影展示。 |
| **家長輔導** | 下載對應科目的學習套裝，按章節逐步引導孩子完成練習。 |
| **補習班使用** | 可根據學生程度選擇「完整學習套裝」或「精華版筆記」，靈活調整教學節奏。 |
