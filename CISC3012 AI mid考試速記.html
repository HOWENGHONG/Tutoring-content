Chapter 1 — What is AI?

1AI 能做什麼 常考

AI has no limitation in application, but has a limitation in capability — it can only reach a certain level of human intelligence, and mainly replaces labour-intensive jobs. For intelligence-intensive jobs (e.g., system analyst), humans still outperform AI.
應用範圍無限，但能力有限；主要取代勞力密集工作；智力密集工作（如系統分析師）人類仍較強。
拿分關鍵字：no limitation in application / limitation in capability / labour-intensive / intelligence-intensive

2AI vs Traditional Algorithm 常考

A traditional computer program (algorithm/logic) is designed by humans — if a human cannot understand or solve a problem, the algorithm cannot either.
An AI program learns / is created directly from data (e.g., a decision tree or a neural network) — as long as data is available, the problem can be solved even without full human understanding.
傳統演算法：人寫邏輯，人不懂就解不了。AI 程式：直接從資料學習（決策樹／神經網路），有資料就可能解決。

3Three Translators（AIGC）常考

工具翻譯
Assemblerassembly language → machine code
Compilerhigh-level language → machine code
AI LLM agentnatural language → machine code
This gives rise to a new job: AI prompt engineering. Programming is still needed, but the focus shifts to idea / creativity / properties of software development rather than intensive coding.
仍要學程式，但重點轉向創意與軟體開發概念，而非大量寫 code。

4Definitions of AI — 四象限 ★★核心必背

There is no single agreed definition of AI. Definitions are grouped along two axes: Thought vs. Behavior, and Human-like vs. Rational (Ideal) — giving four categories.
Human-like 像人Rational / Ideal 理性
Thought 思考Thinking HumanlyThinking Rationally
Behavior 行為Acting HumanlyActing Rationally
Thinking Humanly＝像人思考（需心智理論，做不到）
Acting Humanly＝像人行動（用 Turing Test 判斷）
Thinking Rationally＝理性思考（用邏輯，難處理不確定）
Acting Rationally＝理性行動（Rational Agent，Ch2、Ch3 主題）

5Turing Test ★★必背

A human questioner communicates via teletype (text) with an unseen respondent; if the questioner cannot reliably tell whether the respondent is a human or a computer, the computer is considered to behave intelligently.
Four cognitive tasks required:
1. Natural language processing — communicating with humans
2. Knowledge representation — storing/retrieving information effectively
3. Automated reasoning — using existing knowledge to answer questions
4. Machine learning — adapting to answer unseen questions
Total Turing Test adds two more requirements about action:
5. Computer vision — to perceive (see)
6. Robotics — to act (move objects)
結論：Building a truly "humanly" AI system requires a precise theory of mind, which we do not have — so it is currently impossible to build humanly AI systems.

6Rational System & Rational Agent 常考

A rational system does not care about the method used — only whether the outcome/result is correct. It usually relies on mathematical and logical models, which makes it more reliable than trying to imitate (sometimes irrational) human behavior.
Rational Agent — an agent (usually a computer) that perceives the environment and outputs correct actions to achieve given goals:
facts (percepts/inputs) → reasoning → actions (outputs)
理性系統只在乎結果正確，不在乎方法像不像人。Rational Agent 是 Ch2、Ch3 主題。

7Risk of AI

  • Fake news generation 假新聞生成
  • Reliability and misuse issues 可靠性與濫用問題
  • Challenges to human labor 對人類勞工的就業衝擊
必答句：AI's purpose is to replace or alleviate human labor (especially labour-intensive jobs), not to completely replace humans.

Chapter 2 — Intelligent Agents

1What is an Agent? ★★必背

An agent is anything that perceives its environment through sensors (input) and acts upon that environment through actuators (output). The processing in between is realized by an agent program — a lookup table is infeasible because the number of possible input combinations is infinite.
Agent＝sensors（輸入）＋ agent program（處理）＋ actuators（輸出）。Lookup table 不可行，因輸入組合無限。
Vacuum-cleaner world:
Percepts = which square (A or B), and whether it is Clean or Dirty
Actions = Move Left, Move Right, Suck, Do Nothing (NoOp)

2Rationality ★★必背四要素

Rationality is judged using a performance measure:
Score = P(Result), where Result = action(Environment).
The performance measure should be designed according to the application's objective.
用績效指標判斷；指標要依應用目標設計。吸塵機世界只看最後地板是否乾淨，不管怎樣走。
Rationality depends on four factors（必背）:
1. The performance measure that defines the criterion of success
2. The agent's prior knowledge of the environment
3. The actions the agent can perform
4. The agent's percept sequence up to now (memory)

3PEAS ★★★必背＋要識舉例

字母英文中文
PPerformance measure績效指標

Automated taxi driver example:

4Properties of Environments — 六對 ★★★超高頻

PropertyDefinitionExample
Fully observable vs Partially observable Whether the agent's sensors can access the complete state of the world A local dirt sensor only knows its own square → partially observable
Deterministic vs Stochastic Whether the next state is completely determined by the current state + action Taxi driving is stochastic due to unobservable/noisy factors
Episodic vs Sequential Whether the quality of an action depends on previous/future episodes Episodic = independent single perception-action pairs (simpler); Sequential = current action affects future decisions (e.g., chess, assembly)
Static vs Dynamic Whether the environment changes on its own over time Chess (with a clock) is dynamic; a puzzle left alone is static
Discrete vs Continuous Whether there is a limited, clearly defined number of percepts/actions Vacuum world (2 squares, dirty/clean) is discrete; real-valued sensor readings are continuous
Single agent vs Multiagent Whether there is more than one agent in the environment Crossword = single agent; chess = competitive multiagent; taxi avoiding collision = cooperative multiagent
背法：六對性質＋每對至少一個例子，考試通常直接問「give an example」。

5Five Types of Agents ★★必背

1. Simple reflex agent
Uses only condition-action ("if-then") rules. Efficient but narrow in application; only works when the environment is fully observable.
2. Model-based reflex agent
For partially observable environments. Maintains an internal state based on percept history to track unobserved aspects. Requires knowledge of (a) how the world evolves independently, and (b) how the agent's own actions affect the world.
3. Goal-based agent
Chooses actions based on the current state, current percept, and a goal to achieve. Less efficient than reflex agents because it must check many states and available actions. This motivates search — Chapter 3.
4. Utility-based agent
A goal alone only tells you whether it is achieved, not how well. Utility is a function mapping a state to a real number representing the degree of success. Utility helps: (a) trade off between conflicting goals, and (b) make decisions when multiple goals cannot all be achieved — choose the option with higher utility.
5. Learning agent
After being deployed, an agent may not act perfectly. From environmental feedback, it learns and adjusts its decisions over time — requires machine learning techniques.

Chapter 3 — Rational Agent by Searching

1Problem Formulation 常考

Initial state + Actions + Goal states = a Search Tree.
For large problems, states are generated at run-time rather than listed in advance:
new state = action(old state), e.g., right([1,0,0]) + [0,1,0].
A solution is a sequence of actions (e.g., [up, left]) leading to a goal; multiple paths may reach the goal, and the agent should choose the best one.

2Suitable Environments for Search ★★必背

This "plan first, then execute" approach requires the environment to be:
性質原因
StaticNo need to worry about changes during formulation
Fully observableThe agent knows its initial state
DiscreteA finite number of actions
DeterministicThe effect of every action is known and certain
一句總結：只適用最簡單的環境。

3Well-defined Problem — 四組件 ★★★必背

  1. Initial state — where the agent starts. 起始狀態。
  2. Successor function / Actions — the set of all possible actions; together with the initial state, this defines the state space (all states reachable from the initial state).
  3. Goal test — applied to a state to check if it is a goal. A test (not a fixed list) is used because some goals are described by properties that cannot be enumerated (e.g., in chess, "checkmate the opponent's king").
  4. Path cost function g — assigns a numeric cost to a path, usually the sum of step costs.
Solution = a path from initial state to a state satisfying the goal test.
Optimal solution = the solution with the lowest path cost among all solutions.

4Classic Examples 要識 formulate

ProblemInitial StateActionsGoal TestPath Cost
Vacuum world Any state left, right, suck, noOp (4 actions) Both squares clean Each step = 1, noOp = 0
8-puzzle Any arrangement Blank moves up/down/left/right Matches goal configuration Each step = 1
8-queens (incremental) Empty board (0 queens) Add a queen to any empty square 8 queens, none attacking 0; state space ≈ 256 tera-states
8-queens (complete-state) 8 queens already placed, one per leftmost columns Move an attacked queen to a safe row 8 queens, none attacking 0; state space = 71 = 5040 (much smaller)
結論必寫：The way a problem is formulated makes a big difference to the size of the search space.

5Search Tree Terminology 常考

  • Expanding — applying the successor function to a state, generating a new set of states (e.g., S → {A, B, C}).
  • Leaf node — a state with no successors (a goal), or one not yet expanded.
  • Fringe — the set of generated-but-not-yet-expanded leaf nodes.
  • Node 五要素 — STATE, PARENT-NODE, ACTION, PATH-COST g(n), DEPTH.
  • Queue — the data structure used to organize the fringe; every search strategy uses one (they differ in ordering).

6Four Evaluation Criteria ★★必背

  1. Completeness — Is a solution guaranteed to be found?
  2. Optimality — Is the found solution the best among all solutions?
  3. Time complexity — How long does it take to find a solution?
  4. Space complexity — How much memory is required?
完備性、最優性、時間複雜度、空間複雜度。任何 search strategy 都用這四個評價。

7Uninformed Search Strategies ★★★Ch3 核心

StrategyExpansion orderComplete?Optimal?Notes
Breadth-first search (BFS) FIFO — expand shallowest first Yes Yes, if path cost is non-decreasing with depth Downside: time/space complexity explodes if branching factor b is large
Uniform-cost search Expand the node with lowest path cost g(n) Yes Yes — guarantees the cheapest solution Requires non-decreasing cost; unsuitable for negative-cost actions
Depth-first search (DFS) LIFO — go to deepest level first No — path may be infinite/looping No Lower time/space complexity; PROLOG's backtracking search is this type
Depth-limited search (DLS) DFS with a predefined max depth d Yes (bounded tree) No Hard to choose a good d — too small misses solutions, too large behaves like DFS
Iterative deepening search (IDS) Repeats DLS with d = 0, 1, 2, ... Yes Yes (if step cost = 1) Combines DFS's space efficiency with BFS's completeness/optimality; good when search space is large and solution depth unknown
Iterative lengthening search (ILS) Like IDS, but limits by path cost instead of depth — — Iterative version of uniform-cost search; saves memory but costs more computation
Bidirectional search Simultaneous forward (from start) and backward (from goal) search, meeting in the middle — — Difficult: backward search needs actions to be reversible, and there may be many goal states
背誦口訣：BFS 淺／UCS 便宜／DFS 深／DLS 限深／IDS 加深／ILS 限成本／Bidirectional 兩頭。

8Avoiding Repeated States 常考

Repeated states can cause infinite loops or inefficiency. Three approaches (increasing difficulty):
  1. Don't return to the state you just came from (reject successors equal to the parent)
  2. Don't create paths with cycles (reject successors equal to any ancestor)
  3. Don't generate any state that has already been generated — check against all expanded states, not just ancestors. Uses a closed list (a set storing every expanded node); if the current node matches one in the closed list, discard it.

9Partial Information — 三種問題 ★★要分辨

類型問題做法
Sensorless / Conformant No sensors, initial state unknown Search over a set of possible initial states, called belief states
Contingency (nondeterministic) Action effects are uncertain Build a tree of possible outcomes; the agent must interleave "search, execute, search, execute…" rather than search once then execute
Exploration Both states and action effects are unknown The agent must experiment (with risk of damage); if it survives, it learns the environment for future use

易錯陷阱 — 考前一定要分清

Ch1 陷阱

Thinking Humanly vs Thinking Rationally：像人思考可以包括情緒、偏見、不理性；理性思考要符合邏輯。

Acting Humanly vs Acting Rationally：像人行動用 Turing Test；理性行動用 Rational Agent，只求結果正確。

Human-like vs Rational：人可能不理性；理性系統可以完全不像人，但結果更好。

Ch2 陷阱

Sensors vs Actuators：Sensors = 輸入；Actuators = 輸出。

Fully observable：是看 sensors 能否看到完整狀態，不是看環境簡不簡單。

Static vs Dynamic：有 clock 的象棋是 dynamic，因為環境會隨時間變。

Goal-based vs Utility-based：Goal 只答「有沒有達成」；Utility 答「有多好」，可權衡衝突目標。

Simple reflex vs Model-based reflex：Simple 只看現在 percept；Model-based 有 internal state，記得過去。

Ch3 陷阱

BFS vs Uniform-cost：BFS 按深度一層層；UCS 按 path cost 先走最便宜。

DFS vs DLS vs IDS：DFS 無限深可能 loop；DLS 加深度上限 d；IDS 重複 DLS，d 一直增加。

Complete vs Optimal：Complete = 一定找到解；Optimal = 找到最好解。

Goal test vs Path cost：Goal test 檢查是否到達目標；Path cost 計算這條路有多貴。

Sensorless vs Contingency vs Exploration：Sensorless 不知初始狀態；Contingency 行動效果不確定；Exploration 狀態和效果都未知。

英文答題模板 — 直接背

模板 1：What is AI?

There is no single agreed definition of AI. AI definitions can be classified along two axes: Thought vs. Behavior, and Human-like vs. Rational. This gives four categories: Thinking Humanly, Thinking Rationally, Acting Humanly, and Acting Rationally. The standard test for Acting Humanly is the Turing Test, which requires natural language processing, knowledge representation, automated reasoning, and machine learning. The Total Turing Test adds computer vision and robotics. The representative of Acting Rationally is the Rational Agent.

模板 2：What is an Agent?

An agent is anything that perceives its environment through sensors and acts upon that environment through actuators. The processing in between is realized by an agent program. Rationality is judged using a performance measure, and depends on four factors: the performance measure, the agent's prior knowledge of the environment, the actions the agent can perform, and the agent's percept sequence up to now. The task environment can be described using PEAS: Performance measure, Environment, Actuators, and Sensors.

模板 3：Explain a well-defined problem

A well-defined problem has four components: initial state, successor function/actions, goal test, and path cost function. The initial state is where the agent starts. The successor function defines all possible actions and, together with the initial state, defines the state space. The goal test checks whether a state is a goal. The path cost function assigns a numeric cost to a path. A solution is a path from the initial state to a state satisfying the goal test. An optimal solution is the solution with the lowest path cost.

模板 4：Compare BFS and DFS

BFS uses FIFO and expands the shallowest node first. It is complete and optimal if path cost is non-decreasing with depth, but its time and space complexity can explode when the branching factor is large. DFS uses LIFO and goes to the deepest level first. It is not complete because the path may be infinite or looping, and it is not optimal, but it uses less memory. PROLOG's backtracking search is a type of DFS.

模板 5：What environments are suitable for search?

This "plan first, then execute" approach requires the environment to be static, fully observable, discrete, and deterministic. Static means no need to worry about changes during formulation. Fully observable means the agent knows its initial state. Discrete means a finite number of actions. Deterministic means the effect of every action is known and certain. Therefore, it only applies to the simplest environments.
