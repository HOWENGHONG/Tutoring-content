Section A — Marking Guide
Section A——評分要點

  • (a) PEAS: award marks for a reasonable P (books correctly shelved, speed, minimal damage/misplacement), E (library layout, shelves, other patrons, books/drop-box), A (gripper/arm, wheels/motors, drop-box scanner), S (camera, RFID/barcode reader, location sensor). (~2.5 marks each)
    (a) PEAS：合理的P（正確上架、速度、減少損壞／放錯）、E（圖書館格局、書架、其他讀者、書籍／還書箱）、A（夾爪／手臂、輪子馬達、還書箱掃描器）、S（攝影機、RFID／條碼讀取器、位置感測器）皆可給分（每項約2.5分）
  • (b) 2 marks per pair × 6 pairs, for a correct classification + reasonable one-line justification.
    (b) 每對2分 × 6對，答對分類＋合理的一句話理由即可給分
  • (c) Model-based reflex agent or goal-based agent are both defensible; full marks require correctly explaining that a purely simple reflex agent will not work because the environment is partially observable.
    (c) 基於模型的反射型代理人或目標導向型代理人皆可接受；需正確說明純粹的簡單反射型代理人行不通，因為環境是部分可觀察的，才能拿滿分
  • (d) Initial state (robot's starting position, book to be shelved), Successor function (possible moves), Goal test (book placed correctly), Path cost (e.g., time/distance/number of moves).
    (d) 初始狀態（機器人起始位置、待上架的書）、後繼函數（可能的移動）、目標測試（書本正確放置）、路徑成本（例如時間／距離／移動次數）
